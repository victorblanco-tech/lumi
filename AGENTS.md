# Working agreement

When the user authorizes autonomous implementation and testing, continue the
authorized task through implementation, regression tests and relevant real UI
acceptance. A progress update, incidental question or clarification from the
user is not a request to stop. Answer it briefly in commentary and resume the
unfinished work in the same turn.

Do not end a turn merely to report an intermediate milestone or ask whether to
continue already-authorized work. Pause when the user requests it, or when a
real blocker requires their decision or permission. Never bypass permissions
or expand the task's authority to avoid a pause. Report unverified scenarios
honestly; do not call a build or automated test full UI acceptance.
