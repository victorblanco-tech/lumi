# Lumi 0.5.0-dev-10 — authoritative Rekordbox beatgrid

## Outcome

Track Editor, Local Playback and Live Decks now use the exact Rekordbox bar
phase as well as the exact ANLZ beat timestamps. Lumi no longer relabels the
first analysis marker as beat 1 when the source analysis starts on beat 2, 3 or
4.

## Correctness changes

- Canonical import starts at the first actual Rekordbox downbeat.
- Every retained source beat must follow the exact 1-2-3-4 cycle.
- Source millisecond timestamps are copied unchanged; no BPM-derived grid is
  substituted.
- Raw source phrase positions receive the same leading-partial-bar offset.
- Malformed or incomplete grids fail closed.
- The DAT content hash is part of the analysis revision, so a last-minute grid
  edit is detected even when OneLibrary's counters do not change.
- A changed DAT from the same trusted USB promotes atomically while Lumi-owned
  phrase revisions, role choices and lighting configuration remain owned by
  Lumi.

## Regression evidence

The regression fixture reproduces a real grid that starts on source beat 4 at
0 ms. The first canonical marker is now the source beat 1 at 387 ms and all
later marker timestamps remain byte-derived source facts. An inconsistent
source sequence is rejected.

The connected `DJ VIC GRAY` OneLibrary source exposes `My Favourite Regrets
(Vic DJ Edit)` as track 1237 with 603 source markers; the real ANLZ begins on
beat 4. This is the track used for the final read-only source comparison and
native editor verification.
