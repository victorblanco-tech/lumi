# Lumi 0.5.0-dev-29

This development release restores automatic Light Plans for tracks without a
Rekordbox Track Color while keeping all Theme Strategy boundaries exact.

## User-visible behavior

- Track Color is optional. Neutral and Prefer Themes remain available when a
  track has no color.
- A non-matching Theme or AutoLoop configured as `Only` is never selected.
- Lumi selects among the eligible Themes with the best exact Phrase Role
  coverage.
- A later Phrase Role without an AutoLoop mapping no longer discards the whole
  plan. Lumi sends no command at that boundary, so the currently running
  SoundSwitch AutoLoop continues until the next mapped cue.
- A Theme must map the opening Phrase Role before it can start a track.

## Current-library result

For `90s Bitch - Extended Mix`, BLUE PINK remains excluded without the required
Pink Track Color. BLUE RED GREEN is the configured default and has equal best
coverage with GREEN PINK. It now produces a complete track plan with one safe
no-op at the currently unmapped `PRE DROP` Phrase Role.

## Safety

The change is compile-time only. Pro DJ Link, Ableton Link and realtime MIDI
execution remain isolated. An unmapped phrase cannot emit a guessed AutoLoop,
different Phrase Role or automatic Theme switch.
