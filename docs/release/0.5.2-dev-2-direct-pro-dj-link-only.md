# 0.5.2-dev-2 – Direct Pro DJ Link only

Status: development evidence · 2026-08-31

Connected Decks now has one explicit production provider: Lumi's supervised,
read-only Pro DJ Link bridge. Lumi no longer publishes the retired `Lumi Deck
Input` CoreMIDI destination and cannot silently switch to Beat Link Trigger
MIDI when the bridge is unavailable.

## Delivered

- removed `lumi-blt-midi` from the production engine dependency graph;
- removed the BLT provider and fallback branches from engine orchestration;
- removed BLT snapshot output, Swift decoding exceptions and legacy setup UI;
- direct Pro DJ Link diagnostics remain visible and fail closed;
- architecture checks reject a future product dependency or Swift runtime UI
  for the retired BLT path.

The isolated historical adapter crate and its protocol evidence remain in the
repository for provenance. They are not linked into the shipped engine.

## Verification

- production and test engine targets compile without BLT;
- 92 engine unit regressions pass (three hardware fixtures remain opt-in);
- 52 Live Workspace presentation regressions pass;
- 62 Library Workspace regressions pass;
- direct bridge diagnostics accept unbounded bridge sequences and player IDs
  in the supported one-through-four range.
