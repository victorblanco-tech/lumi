# Lumi 0.6.3 — Public Beta

A simpler, reliable installation route for the Mac. This patch replaces the
drag-to-folder shortcut with the standard **macOS Installer**.

## Install or update

1. Download **Lumi-0.6.3-arm64.dmg** and verify its SHA-256 checksum.
2. Finish your show and quit Lumi. Open the DMG and double-click **Install Lumi.pkg**.
3. Follow macOS Installer; it creates `/Applications/Lumi` automatically.
   Administrator approval may be required.
4. Eject the DMG and open Lumi from `/Applications/Lumi`.

This beta is not Apple-notarized. If macOS blocks the installer or app, use
**System Settings → Privacy & Security → Open Anyway** for the verified official download.

Existing tracks, phrases, MIDI mappings and settings are preserved. Dev and RC
stay in their own folders with separate data. A fresh Production installation
starts empty. Licenses and complete corresponding-source archives are included
in **Licenses & Sources** in the DMG.

## What stays the same

Live performance, waveform rendering, USB sync and lighting integrations are
unchanged. **Lumi Remote 0.1.1** remains the compatible iPhone app; no iPhone
reinstallation is needed for this packaging update. The simulator is independent.

Requires Apple Silicon and macOS 15 or newer.
