# Lumi 0.3.0-rc.1

Status: **Release candidate / owner acceptance**
Date: **2026-08-08**

This is the first versioned, installable Lumi Preview release candidate for
Apple Silicon. It is built from `release/v0.3.0`, tagged `v0.3.0-rc.1` and is
published on GitHub as a pre-release rather than a production release.

## Included

- read-only Rekordbox playlist and analysis import into Lumi-owned storage;
- RGB Track Lighting Editor with exact beatgrid and editable Lumi phrases;
- stable two-deck Local Playback with a rolling phrase and AutoLoop Plan;
- persistent four-bank/32-slot SoundSwitch mappings;
- automatic phrase-boundary MIDI output and Local Playback MIDI Clock;
- isolated Stable, Preview and Dev identities, preferences and databases;
- local data backup and explicit non-overwriting channel clone tools.

## Install

Download both assets from this GitHub pre-release:

- `Lumi-Preview-0.3.0-rc.1-arm64.dmg`
- `Lumi-Preview-0.3.0-rc.1-arm64.dmg.sha256`

Verify the checksum, open the DMG and drag **Lumi Preview** to Applications.
This build is ad-hoc signed and not notarized, so macOS may require the
documented one-time **Open Anyway** action.

## Acceptance focus

- complete a full-song Local Playback → SoundSwitch → DMX run;
- verify Live → Library → Live output continuity;
- verify timing compensation and phrase-boundary alignment;
- perform the 100-trigger and MIDI endpoint reconnect soak.

## Known limitations

- no Developer ID signature or Apple notarization;
- the engine is still an app-scoped helper rather than an autonomous service;
- connected decks use the Beat Link Trigger MIDI adapter; production Pro DJ
  Link hardware evidence is pending;
- no iPhone companion release yet;
- the repository remains `UNLICENSED`; this private RC is not yet advertised as
  an open-source production release.

Run only one Lumi channel at a time while using live MIDI and lighting output.
