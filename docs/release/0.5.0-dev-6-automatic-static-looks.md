# Lumi 0.5.0-dev-6 — automatic Static Looks

Date: 2026-08-22

This development build connects physically verified SoundSwitch Static Looks to
compiled Light Plans. It preserves the stable `0.4.0` integration architecture:
Pro DJ Link, Ableton Link, AutoLoop output and UI rendering remain separate.

## Test focus

1. In `Integrations → Lighting Outputs → Static Looks`, confirm both Activation
   and Release for each physically proven mapping and save.
2. In `Light Plans → SoundSwitch Modifiers`, configure a rule and save.
3. In `Plan Preview`, choose a track and Theme. Use `New variation` until the
   desired Static Look appears or temporarily set Application Rate to 100%.
4. Load that track in `Live → Local Playback`, choose `Start` and play through
   the selected phrase.
5. Confirm that SoundSwitch selects the Static Look once, its AutoLoop continues,
   and the next `No Override` phrase releases it once.
6. Pause/resume in the same phrase: no additional Static Look toggle may occur.
7. Switch `Off`: a Lumi-managed active look must be released once.

Color Override output is not enabled in this build.
