# Lumi `0.4.0-dev-55` — deterministic transport and output timing

Dev-55 makes every confirmed playback action an explicit, exactly-once
AutoLoop execution boundary and activates the signed lighting timing offset.

## Delivered

- explicit execution epochs for Start, stopped-to-playing, track load, master
  handoff and confirmed position landing;
- exactly one current-cue reassertion after resume, Hot Cue, seek or beatjump,
  including landings inside the same phrase;
- cancellation and BPM rescheduling limited to unsent work; completed output
  is immutable;
- negative offset as a pre-trigger and positive offset as a delay, with running
  changes applied from the next phrase boundary;
- accurate Live and Integration UI wording for saved, pending and applied
  timing plus tempo-update freshness.

## Verification

- deterministic 100-action reducer and executor matrices: 100 expected cues,
  100 completed, zero failures and no duplicate output;
- representative CDJ-1500X network matrix: stopped-to-playing, Pause/Start,
  forward/backward and same-phrase landings each emit exactly once;
- 60-second optimized MIDI soak: p95 10.036 ms, p99 10.048 ms and zero queue
  saturation;
- actual Lumi desktop UI: Arm, Start, Pause/resume, seek, live BPM and deferred
  timing-offset activation verified;
- actual SoundSwitch UI: one Link peer, exact `155.000 -> 161.510` BPM response,
  responsive AutoLoop selection and no interruption from app switching;
- UI Quit removes the Link peer within the bounded cleanup window while the
  inactive launchd engine and stable MIDI endpoints remain available;
- complete technical, functional and Apple application gates pass.

## Scope boundary

This is an unsigned Apple Silicon development build, not an RC. E5-04 still
requires the one-hour Wi-Fi/Ethernet matrices and physical CDJ-1500X,
SoundSwitch, Control One and DMX evidence.
