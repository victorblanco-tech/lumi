Fresh installs are empty. No personal Library, mappings, USB markers or pairing
credentials are included. Mac requires Apple Silicon/macOS 15+, Remote iOS 18+.

not TestFlight. The iOS Simulator artifact must retain app-scoped Keychain
entitlements. Security, documentation and protected Foundation gates must pass.
