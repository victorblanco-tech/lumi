# Lumi 0.5.0-dev-4

## Outcome

SoundSwitch AutoLoop MIDI Learn now has 128 unique addresses. Mapping a button
in Bank 2, 3 or 4 can no longer overwrite the same numbered button in another
bank.

## User-visible changes

- `Test Controller` is renamed to `Virtual Controller`.
- Every button in `Banks & AutoLoops` has a direct Test action.
- Every Virtual Controller button has explicit Learn and Test actions.
- `Send Learn & Next` advances through all 32 AutoLoops and then the next bank.
- The selected bank, AutoLoop, MIDI channel and note remain visible while
  mapping.

SoundSwitch still requires the user to arm `Map` for each destination control;
it does not expose a supported bulk-import or mapping-confirmation API to Lumi.

## MIDI contract

- Bank 1–4 selectors: Channel 16, Notes 60–63.
- Bank 1 AutoLoops: Channel 13, Notes 64–95.
- Bank 2 AutoLoops: Channel 14, Notes 64–95.
- Bank 3 AutoLoops: Channel 15, Notes 64–95.
- Bank 4 AutoLoops: Channel 16, Notes 64–95.

The bank number is retained through command decoding, realtime scheduling and
the final CoreMIDI pulse.
