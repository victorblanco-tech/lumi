# Lumi 0.3.0 development release and known limitations

Status: **Local acceptance build**
Date: **2026-08-08**

## What this build proves

`0.3.0-dev` is the first installable Apple Silicon product slice containing:

- read-only Rekordbox playlist and analysis import into Lumi-owned storage;
- the Library and Track Lighting Editor with RGB waveform, exact beatgrid and
  editable Lumi phrase timeline;
- two fixed Local Playback decks with authoritative audio transport;
- a rolling phrase and AutoLoop Plan using persisted SoundSwitch Banks and
  slots;
- automatic phrase-boundary MIDI execution and a dedicated Local Playback MIDI
  Clock;
- parallel manual Control One operation, proven in the initial physical test;
- compact technical health and local integration diagnostics.

Lumi has no runtime internet dependency. Track metadata, audio analysis,
configuration, playback and lighting planning remain local to the Mac.

## Supported acceptance environment

- Apple Silicon Mac;
- macOS 15 or newer;
- SoundSwitch is optional for Library/editor testing and required for physical
  light-output acceptance;
- Rekordbox must be closed before Lumi creates a read-only analysis snapshot;
- Beat Link Trigger simulated decks can exercise the connected-deck adapter;
  real Pro DJ Link hardware evidence remains pending.

## Install and verify

1. Download both `Lumi-Preview-0.3.0-dev-arm64.dmg` and its `.sha256` file from
   the same GitHub Release.
2. In Terminal, change to the download folder and run:

   ```bash
   shasum -a 256 -c Lumi-Preview-0.3.0-dev-arm64.dmg.sha256
   ```

3. Open the DMG and follow `README - Install Lumi Preview.txt`.
4. Drag Lumi Preview to Applications.
5. Use the documented one-time **Open Anyway** flow because this early build is
   not signed with a paid Developer ID or notarized by Apple.

## Known limitations

- The app is ad-hoc signed. Gatekeeper cannot identify the publisher or verify
  an Apple notarization ticket.
- The Rust engine is an app-scoped embedded helper, not yet an autonomous
  SMAppService. Closing Lumi stops the engine and integrations.
- The final repeat full-song SoundSwitch/DMX timing run, 100-trigger soak and
  endpoint reconnect transcript remain release gates.
- Connected-deck input currently uses the Beat Link Trigger MIDI adapter; native
  Pro DJ Link support and real hardware acceptance remain future work.
- No iPhone companion, Windows build, automatic updater or in-app update check
  is included.
- Output Profile Builder is deferred. The current product provides the built-in
  four-bank/32-slot SoundSwitch mapping.
- Early development builds may change the local schema. Keep Rekordbox backups;
  Lumi never writes to the Rekordbox source database.
- Lumi Preview uses its own preferences and `Application Support/Lumi Preview`
  database. It never opens the Stable `Application Support/Lumi` database.

## Open-source publication gate

The repository source can be made public immediately, but it is not legally
open source while the workspace remains `UNLICENSED`. An OSI-approved project
license must be selected before the first public release is advertised as open
source.
