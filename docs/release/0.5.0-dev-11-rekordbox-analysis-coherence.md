# Lumi 0.5.0-dev-11 — Rekordbox analysis coherence

## Outcome

Beatgrid, detailed RGB waveform, raw Rekordbox phrases, hot cues and duration
now enter Lumi as one coherent, read-only analysis projection. The Track Editor
uses the exact Rekordbox millisecond clock for every visual layer.

## Existing-library repair

The next explicit sync of a selected USB playlist promotes a changed complete
DAT/EXT/2EX fingerprint. For timelines affected by the old leading partial-bar
projection, Lumi appends a source-reconcile revision that:

- removes the artificial one-beat prefix;
- moves only unchanged source-derived boundaries onto corrected beats;
- preserves boundaries the user deliberately moved;
- preserves phrase roles and per-phrase AutoLoop strategies.

No track, playlist, Light Plan or lighting-output configuration is deleted.

## USB workflow

The playlist browser now mirrors Rekordbox folders and nested folders. All
folders and playlists start collapsed, while search reveals only matching
playlists and their ancestors.

## Verification

- Parser, device revision, SQLite transaction and engine regression suites pass.
- Swift Library Workspace tests pass, including hierarchy/search behavior.
- The mounted `DJ VIC GRAY` source was synchronized against an online SQLite
  backup, not live user data. `My Favourite Regrets (Vic DJ Edit)` retained all
  authored roles and custom boundaries, moved to timeline revision 11, and now
  contains 600 exact beats, 17 source phrases and a 233,420 ms waveform clock.
