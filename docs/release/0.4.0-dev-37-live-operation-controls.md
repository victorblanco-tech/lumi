# Lumi 0.4.0-dev-37 — Live operation controls

## Problem

Off, Arm, Start, Pause and Off were guarded by the same global state revision
as high-rate Pro DJ Link deck telemetry. A beat or position event arriving
between the macOS snapshot and an Arm command could therefore reject a valid
user transition and make the UI fall back to Off.

## Decision

Operation commands remain constrained by the explicit operation state machine:

- Off → Armed
- Armed or Paused → Live
- Live → Paused
- every state → Off

A valid transition is applied against the current runtime revision. Unrelated
deck telemetry is not a concurrency conflict for an operation control. An
invalid transition with a stale revision continues to return the existing
revision-conflict response, preserving safe failure for genuinely obsolete
commands.

## Verification

- The engine regression suite advances deck state after the UI revision was
  captured and proves that the stale Arm command still reaches Armed.
- The authenticated process test continues to cover stale invalid commands.
- Physical CDJ validation is required after installing Dev-37.
