# Lumi 0.5.0-dev-25 — Rekordbox track colors

This development build makes the imported Rekordbox track color visible and
consistent throughout the preparation and performance workflows.

## Source fidelity

- OneLibrary `color_id` is the authoritative fixed palette identity.
- User-renamable Rekordbox labels do not influence the RGB projection.
- A normal USB playlist synchronization backfills colors missed by older Lumi
  builds while the independent analysis and phrase timelines remain intact.

## Presentation

- Tracks and Local Playback use the same compact circular color swatch.
- Local Playback and Live Decks receive the same library-backed RGB value.
- Tracks without a Rekordbox color show a neutral hollow ring.

## Verification

- Rust regression coverage validates custom labels and safe color backfill.
- Swift package coverage validates the fixed presentation palette.
- The connected GRAY OneLibrary source resolves a custom-labelled blue track
  to `#3280FF` without writing to the USB.
