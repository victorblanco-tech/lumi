# Lumi 0.5.0-dev-35

This Dev release completes Epic 7.

## Visible changes

- Configurable Track Workflow in Settings with ordered steps, visual identity and smart quality gates.
- Dynamic preparation queues and counts in Tracks.
- One shared workflow picker in the Track Editor.
- Fixed `New track versions` inbox.
- Guided successor comparison with exact-beat phrase reuse or `Keep Separate`.

## Safety and architecture

- schema 17 uses optimistic catalog, assignment and review revisions;
- workflow and version review remain isolated in the Library worker;
- phrase reuse never guesses, stretches or overwrites the predecessor;
- system safety queues cannot be hidden by user configuration.
