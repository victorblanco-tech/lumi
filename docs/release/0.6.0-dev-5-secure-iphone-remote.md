# Lumi 0.6.0-dev-5 – secure native iPhone Remote path

This development increment turns the isolated Remote projection from
`0.6.0-dev-4` into a complete, opt-in local-network path ready for physical
iPhone acceptance. Lumi Remote is independently versioned as `0.1.0-dev-3`.

## Delivered

- separately packaged and supervised Remote Gateway, disabled until enabled in
  `Integrations > iPhone Remote`;
- channel-scoped Bonjour discovery for Production, RC and Dev;
- persistent self-signed Mac installation identity and pinned rustls TLS;
- one-use five-minute QR invitation, matching six-digit confirmation and
  explicit Mac approval;
- per-device Keychain credential on iPhone and verifier-only protected trust
  state on Mac;
- paired-device list, last seen, revoke and one-Controller transfer UI;
- native iPhone TLS transport, reconnect and foreground/background lifecycle;
- dark portrait and landscape booth presentation using the Mac's current
  user-configured Phrase colors;
- actual OFF/ARM/START/PAUSE, Ableton Link, timing offset, future Theme,
  AutoLoop and cue-lock commands over the revision-safe allowlist;
- authoritative command acknowledgement, fixed feedback and success/error
  haptics;
- Camera deep-link pairing through the `lumi://pair` URL scheme;
- explicit Bonjour declarations and third-party notices for gateway security
  and discovery crates.

## Safety boundary

The Remote Gateway is not part of Pro DJ Link ingestion, SoundSwitch MIDI or
Ableton Link publication. It reads a presentation-safe projection at bounded
rates and hands allowed commands to the engine through a bounded loopback
queue. A closed, suspended, slow or malicious client queues nothing and cannot
interrupt the show.

## Verification

- 29 Rust Remote protocol/gateway tests, including a real pinned-TLS session;
- 17 native Remote Client contract/state tests;
- 3 Remote Live presentation tests;
- 58 macOS Library/Integrations tests;
- real iOS Simulator and macOS Dev product builds;
- packaged Remote Gateway executable, embedded identity and LaunchAgent plist
  validation.

The remaining gate is deliberately physical: actual iPhone Local Network
permission and pairing, rotation/gesture/accessibility checks, two-device
Controller transfer, and the combined hardware/SoundSwitch soak are not claimed
from automated or Simulator evidence.
