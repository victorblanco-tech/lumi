# Lumi 0.5.0-dev-39 — waveform color fidelity

## Outcome

Lumi again renders the approved CDJ/Rekordbox-style RGB waveform palette in
Track Editor, Local Playback and Live Decks. The change is deliberately limited
to display-channel order; waveform geometry, resolution, beat alignment and
timing remain unchanged.

## Regression protection

- One shared Design System mapping owns waveform amplitude and RGB output.
- Tests pin the packed PWV5 channel order and existing amplitude curve.
- Silent samples remain omitted.
- Desktop acceptance covers a real imported track in both editing and playback
  contexts before packaging.

## Installation identity

The Dev build remains isolated under the `Lumi Dev` bundle identity and keeps
using the existing `Lumi Dev` application-support database. Older Dev app
bundles can be removed without touching that data.
