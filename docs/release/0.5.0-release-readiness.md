## Release identity

- version: `0.5.0`

- data: `~/Library/Application Support/Lumi`
- platform: Apple Silicon, macOS 15+

## Clean-data gate

Production and RC set `LUMI_SEED_DEMO_LIBRARY=0`; Dev sets it to `1`. The
packager validates both the app metadata and embedded SMAppService environment.
A fresh-production engine regression proves zero tracks, playlists and trusted
USB sources and rejects known personal-data markers. The DMG never contains an
Application Support database.

Before local installation, any existing Production database and preferences
are archived to a timestamped backup. The Dev database is neither opened nor
modified by this release procedure.
