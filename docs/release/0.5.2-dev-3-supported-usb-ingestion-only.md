# 0.5.2-dev-3 – Supported USB ingestion only

This hardening slice removes the retired Rekordbox XML and direct local
Rekordbox-database operations from Lumi's authenticated product protocol.
Mounted Rekordbox OneLibrary USB media is now the only product ingestion path.

## Safety boundary

- Lumi continues to inspect and synchronize selected USB playlists through the
  isolated, read-mostly USB worker.
- Existing Production data is neither reset nor migrated automatically.
- Old XML/direct-database command kinds are rejected by the engine.
- An architecture gate prevents both Rust and Swift product commands from
  accidentally reintroducing those operations.

Internal parsing crates and historical tests may remain until the later
dead-code cleanup slice, but they are not reachable from the installed app.
