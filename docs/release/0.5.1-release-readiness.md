# Lumi 0.5.1 release readiness

## Release identity

- version: `0.5.1`
- status: Public Beta
- channel: Production
- bundle identifier: `co.victorblan.tech.lumi`
- app: `/Applications/Lumi/Lumi.app`
- data: `~/Library/Application Support/Lumi`
- platform: Apple Silicon, macOS 15+

## Scope and data safety

0.5.1 contains no functional or schema change from 0.5.0. It completes the
public distribution package. A fresh Production install remains empty and an
upgrade preserves the isolated Production database. No Dev data, personal
tracks, USB identities or personalized SoundSwitch mappings are packaged.

## Public distribution gate

- Public Beta labeling, user guide and field-test issue form are present.
- Lumi is EPL-2.0 with a separate trademark notice.
- Third-party runtime licenses and notices are included in the app and DMG.
- Complete corresponding source for the separately executed Carabiner/Ableton
  Link helper and pinned Java bridge dependencies is included in the DMG.
- The release SPDX inventory covers Rust, Java, OpenJDK, SQLCipher/OpenSSL and
  the Link helper.
- Repository and history scans found no token, private key, user database,
  music library or personalized configuration release blocker.

## Release evidence

The tagged release is accepted only after the complete local verification,
security audit, clean production package and mounted-DMG checks pass. The GitHub
release contains the Apple Silicon DMG, independent SHA-256 checksum, SPDX SBOM
and these release notes.

The app is ad-hoc signed and intentionally not notarized. Repository visibility
is changed separately after the release assets and public default-branch safety
settings are confirmed.
