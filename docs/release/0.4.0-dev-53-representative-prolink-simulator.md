# Lumi 0.4.0-dev-53 — representative Pro DJ Link simulator

Dev-53 establishes the test foundation for the reopened deterministic Live
integration epic. It does not yet contain the production ingress refactor.

## Included

- default `cdj-1500x` simulator traffic profile;
- CDJ status at 10 Hz, PrecisePosition at 50 Hz and exact USB beat-grid beats;
- deterministic stale-position bursts ending in the current position;
- authenticated manual burst trigger;
- visible profile, cadence, packet, burst, peer and traffic-error diagnostics;
- classic low-traffic comparison profile;
- updated Epic 5, ADR-0027/0033/0034 and one-page implementation plan;
- dev-52 explicitly rejected as Live Decks performance evidence.

## Local evidence

- all 14 simulator tests pass;
- generated announcement, status, beat and 60-byte PrecisePosition packets
  round-trip through pinned beat-link 8.0.0;
- the shaded simulator JAR and local simulator verification pass;
- the self-contained ARM64 DMG passes checksum, signature and mounted-bundle
  version verification.

## Still required

- install the updated self-contained simulator app on the Mac mini;
- prove two-host discovery and sustained counters;
- implement E5-01/E5-02 source-side and consumer separation;
- complete the one-hour simulator soak before another physical-CDJ session.

Dev-53 is development-only and is not an RC candidate.
