# Lumi 0.5.0-dev-30

This development release makes the normal start-of-set workflow deterministic
with physical CDJ-1500X players.

## User-visible behavior

- A track loaded before Lumi enters Live Decks is recognized while the player
  is still paused/cued.
- Lumi can prepare the exact local waveform, phrases and Light Plan before the
  DJ presses Play.
- The first Play is no longer dependent on waiting for a later phrase change
  to establish track identity.

## Compatibility

CDJ-1500X firmware 1.10 publishes a 512-byte extended status packet. Beat Link
8.0 reads its transport correctly but leaves the legacy loaded-track identity
empty. Lumi reads the exact Rekordbox ID from the extended field and resolves
it only through trusted USB data. Unsupported packets remain unknown and hold
automatic output safely.

## Verification

- Java unit tests cover loaded, unloaded and unsupported layouts.
- A read-only physical test with two paused/cued CDJ-1500X players immediately
  returned the exact expected IDs 1256 and 1237.
- No transport or player command is sent by this compatibility decoder.
