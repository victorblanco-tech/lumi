# Lumi 0.6.2-dev-7 / Remote 0.1.1-dev-4 — Live timing edits

An offset selected from Remote could be rejected because the general engine
revision had advanced during playback. The next projection immediately cleared
the error. The original Menu also rebuilt with live updates and only offered
−100 to +100 ms, despite the engine supporting −250 to +250 ms.

Remote now has a stable timing sheet with the full range, a slider, 1 ms fine
adjustment, Reset, Cancel and Apply. A draft is not reset by incoming player
updates. Conflicts remain visible. NEXT PHRASE identifies a pending change;
Mac Live shows the engine's applied/pending value and identifies a session
override separately from its saved startup default.

The engine checks the expected timing value instead of unrelated show revisions
for new Remote clients. Concurrent offset changes conflict; legacy clients
retain their original revision contract. Playing shows defer activation until
the next phrase without retriggering the current AutoLoop.
