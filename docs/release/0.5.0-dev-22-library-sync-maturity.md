# Lumi 0.5.0-dev-22 — Library sync maturity

This development build hardens the complete pre-show source and editing flow.

## Import & Sources

- CHRM and GRAY remain independent trusted sources even when equal-model FAT
  media reports the same filesystem UUID or hardware serial.
- Explicit Add, Refresh or Sync writes one hidden `.lumi-source.json` identity
  marker. It contains only Lumi's opaque source ID; PIONEER, Rekordbox, audio
  and analysis data remains read-only.
- USB inspection and sync run in a bounded child process. A stalled USB is
  terminated after 75 seconds without blocking the persistent realtime engine.
- Opening or closing a source lane no longer starts a surprise scan or inserts
  a transient page-level panel.
- A changed same-source analysis refreshes beatgrid, waveform, cue points and
  raw phrases atomically while preserving Lumi-authored phrase work.

## Tracks and Editor

- Search updates while typing and exposes a visible clear action.
- Native column headers sort the complete server-side result with deterministic
  pagination.
- `Reuse Lumi Phrases` suggests likely older edit/mashup versions but applies
  only after explicit confirmation and an exact total-beat match.

## Verification

- Portable Rust lint, architecture, full test and 10,000-track benchmark pass.
- Complete Apple protocol, design-system, Live, Library, engine-client, build
  and visual-evidence verification pass.
- Native process tests run serially to guarantee exclusive ownership of fixed
  CoreMIDI endpoints.
- Physical CHRM and GRAY media are inspected through the installed app before
  delivery; their Rekordbox databases are byte-checked before and after.
