# `0.4.0-dev-40` output deadlines and clean shutdown

## Scope

This Dev release is a reliability correction for physical Pro DJ Link → Lumi
→ CoreMIDI → SoundSwitch use. It deliberately contains no visual redesign.

## Proven root causes

1. A prepared AutoLoop was treated as already emitted when the domain entered
   its phrase. A near-boundary status update could therefore suppress the
   fallback while stale cleanup cancelled the still-pending deadline.
2. Scheduling the following phrase advanced the realtime generation. If the
   previous pulse was due but had not yet been dequeued, it was cancelled.
3. A start/Hot Cue/beatjump without a prepared Bank waited for the next Pro DJ
   Link beat after the 50 ms Bank settle period instead of delegating that
   exact deadline to the realtime lane.
4. Closing Dev-39 ended the UI but intentionally left the persistent engine
   alive. That engine retained the Pro DJ Link bridge and an Ableton Link peer,
   and queued anchors could relaunch Carabiner while the engine was stopping.
5. Physical CDJ traffic can contain short gaps of more than three beat packets.
   The original 1.25 s lower stale limit repeatedly held and recovered Link on
   an otherwise healthy 155 BPM session.
6. Lumi launched Carabiner with `--daemon`. The tracked process forked and
   exited, leaving the real Link peer adopted by launchd and impossible for the
   engine's normal child teardown to stop.
7. Tracking the foreground child alone was insufficient: the Link worker could
   still be inside a socket exchange when macOS reached its bounded graceful
   shutdown deadline. The supervisor then killed the engine before the worker
   reached its queued shutdown command.

## Corrected invariants

- scheduled and emitted are distinct states;
- phrase entry does not invalidate its own prepared pulse;
- the next phrase uses the same transport generation;
- only a transport invalidation or changed-tempo deadline replacement advances
  the generation;
- stable-tempo packet jitter never reschedules a prepared deadline;
- unprepared Bank fallback fires after the exact 50 ms settle deadline;
- last-window close and Quit own the complete helper teardown;
- an unexpected UI disconnect ends the app-owned engine;
- shutdown cannot start a new Link helper;
- eight missing beats, bounded to 3–8 seconds, distinguish transient UDP loss
  from a real timing-source outage;
- a Lumi-owned Carabiner stays in the foreground as the engine's tracked child.
- teardown kills the exact owned helper before joining the worker, which also
  closes any in-flight socket exchange; helpers merely connected to are never
  terminated by Lumi.

## Required evidence before handoff

- complete Rust, Apple and Pro DJ Link bridge local gates;
- deterministic regression tests for phrase entry, successive same-generation
  scheduling, queue cancellation and post-bank deadline dispatch;
- physical Player 1 multi-phrase loop with SoundSwitch and Ableton Link active;
- action-specific scheduling/dispatch counters with no saturation and no
  dispatch above the accepted 20 ms CoreMIDI budget;
- Quit followed by zero remaining Lumi engine, bridge and Carabiner processes
  and zero Lumi Ableton Link peer.
