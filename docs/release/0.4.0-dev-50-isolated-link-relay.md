# Lumi `0.4.0-dev-50` — isolated Ableton Link Relay

## Outcome

Dev-50 implements phase 1 of Epic 5. Ableton Link is no longer owned by the
lighting/MIDI output worker. Its only input is the selected deck clock, so Lumi
operation state, phrases, plans, Banks and AutoLoops cannot hold, restart or
re-anchor SoundSwitch timing.

## Delivered

- dedicated engine `LinkRelay` with an intentionally narrow clock-only API;
- CdjStatus as the sole effective master-tempo authority;
- immediate playing BPM updates for realtime CDJ pitch-slider movement;
- phase-preserving Carabiner BPM updates;
- no Link Hold on Lumi Off or Pause;
- separate Local Playback MIDI Clock and Link reconciliation calls;
- no implicit helper reconnect or second peer after an active-session failure;
- explicit disable/enable recovery after degradation;
- dev version `0.4.0-dev-50`, build configuration 50.

## Deliberate boundary

Dev-50 does not claim that the legacy predictive AutoLoop executor is stable.
It is left functionally unchanged and will be replaced by the exactly-once
executor in E5-02. Physical SoundSwitch peer and Wi-Fi evidence remain required
before release promotion. Dev-50 has real SoundSwitch evidence for both Local
Playback and direct simulated Pro DJ Link; physical CDJ pitch movement and the
combined Wi-Fi soak remain tracked in E5-04.
