# Lumi 0.5.2 release readiness

## Release identity

- version: `0.5.2`
- status: Public Beta
- channel: Production
- bundle identifier: `co.victorblan.tech.lumi`
- app: `/Applications/Lumi/Lumi.app`
- data: `~/Library/Application Support/Lumi`
- platform: Apple Silicon, macOS 15+

## Scope and data safety

0.5.2 hardens the 0.5.1 runtime without a product-schema migration. A fresh
Production install remains empty and an upgrade preserves the isolated
Production database. No Dev data, personal tracks, USB identities, authored
phrases or SoundSwitch mappings are packaged.

The pre-promotion Dev database and preferences were backed up and the copied
SQLite database passed `PRAGMA integrity_check` before release preparation.

## Acceptance evidence

- The owner accepted direct Production promotion after physical Player,
  Pro DJ Link, Ableton Link and SoundSwitch integration testing.
- The final Dev acceptance pass confirmed two physical Players, master playback
  and saturated local-detail RGB waveforms.
- One physically mounted trusted USB is represented as exactly one connected
  source; an absent equal-model backup remains offline.
- Local Playback was headed-tested with consecutive track replacement and did
  not retain the muted fallback or publish a stale waveform raster.
- The possibly slower visible BPM-slider response is explicitly deferred to the
  first measured `0.6.0` story and is not accepted as evidence of incorrect BPM
  values or broken integration.

## Required release evidence

The tagged release is accepted only after the complete local verification,
security audit, clean Production package, mounted-DMG validation and GitHub
protected-branch checks pass. The published release contains the Apple Silicon
DMG, independent SHA-256 checksum, SPDX SBOM and 0.5.2 release notes.

The app is ad-hoc signed and intentionally not notarized.
