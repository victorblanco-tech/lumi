# Lumi 0.4.0-dev-35 — show-grade hardening evidence

- Date: 2026-08-15
- Channel: Dev
- Architecture: ADR-0031
- Epic: E4-03

## Delivered

- dedicated bounded realtime MIDI scheduling for Bank and AutoLoop output;
- generation-safe cancellation across seeks, hotcues, master changes, Pause
  and Off;
- realtime timing and saturation health in Diagnostics and Live readiness;
- revisioned library polling instead of full library decoding every 250 ms;
- reconnectable persistent engine adapter across UI quit/relaunch;
- engine-owned, validated SQLite backup and restore with rollback;
- SPDX 2.3 SBOM in the packaged artifact.

## Automated gates

The following commands passed on the Apple Silicon development Mac:

```text
./scripts/verify-local.sh functional
./scripts/verify-local.sh technical
./scripts/verify-local.sh security
./scripts/verify-apple.sh
```

The Apple gate passed 51 Live workspace tests, 43 Library workspace tests and
18 engine-client tests, plus application bundle and 22-image visual-evidence
verification. The engine-client suite includes a real process test that issues
concurrent monitor and interactive commands and verifies framing/correlation.

## Realtime AutoLoop soak

A 60-second development soak was run with:

```text
LUMI_AUTOLOOP_SOAK_SECONDS=60 cargo test -p lumi-midi-output \
  --test realtime_soak -- --ignored --nocapture
```

| Counter | Result |
|---|---:|
| Scheduled | 2,127 |
| Emitted | 2,016 |
| Deliberately stale-cancelled | 111 |
| Queue saturation | 0 |
| Queue high-water | 5 / 64 |
| p50 | 0.109 ms |
| p95 | 10.032 ms |
| p99 | 10.075 ms |
| Maximum | 10.108 ms |

The p95 satisfies ADR-0030's 20 ms CoreMIDI-boundary budget. Exact counts prove
that every scheduled item was either emitted or deliberately invalidated; no
item was silently lost or duplicated.

`./scripts/verify-rc-soak.sh` enforces a duration of at least 3,600 seconds and
is the only accepted one-hour RC entry point.

## Interactive application verification

The installed Dev app retained its existing channel database and was exercised
through accessibility automation:

- Integrations Diagnostics displayed `AutoLoop realtime output`, queue `0/64`,
  peak `1`, p95 `0.0 ms` while idle and zero saturation;
- operation state was changed to Armed;
- only the UI process was terminated; the engine PID remained alive;
- reopening the app reattached to the same endpoint and restored Armed without
  resetting runtime state;
- operation state was returned to Off;
- a real engine-owned manual backup completed successfully (256.8 MB).

This UI exercise found and drove a fix for concurrent monitor/interactive IPC
framing before the version was accepted.

## Required before RC promotion

This Dev record deliberately does not claim the following release evidence:

1. one-hour AutoLoop soak through `verify-rc-soak.sh`;
2. physical CDJ-1500X, DJM-V5, SoundSwitch, Control One and DMX timing run;
3. retained two-deck Instruments profile;
4. promotion of the reconnect adapter to a login-capable `SMAppService` and
   engine-crash restart proof;
5. hardened-runtime/notarized signing if distribution becomes public.
