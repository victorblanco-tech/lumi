# Lumi 0.6.2 — Public Beta

This update improves USB synchronization and live editing, together with
**Lumi Remote 0.1.1** for iPhone.

## What's new

- **Change the next phrase from the booth.** Choose a configured Lumi Phrase
  Type, Theme and AutoLoop from Mac Live or iPhone. Changes are committed
  together so a rejected edit cannot leave half an updated plan behind.
- **One saved lighting offset.** Adjust −250 to +250 ms from either client.
  Negative means earlier, positive means later. During playback the new value
  takes effect at the next phrase without restarting the running AutoLoop.
- **Predictable iPhone control.** Controller ownership survives reconnects and
  mode changes. View-only devices are identified clearly; control transfers
  remain an explicit choice on the Mac.
- **More reliable USB sync.** Separate USB identities, full audio verification,
  revision checks before committing and clearer source-specific progress help
  keep the Library aligned with the selected rekordbox export.
- **Updated guides and HQ imagery**, including the enlarged Track Editor and
  instructions for the separate Pro DJ Link Simulator.

Remote communication and command handling also gain bounded reads, clearer
failure outcomes and regression coverage. These changes do not introduce
SoundSwitch timeline correction or a new waveform renderer.

## Install or update

1. Download **Lumi-0.6.2-arm64.dmg** below. Apple Silicon and macOS 15+ are required.
2. Quit Lumi, open the DMG and use its installation shortcut for `/Applications/Lumi`.
3. Open Lumi. This public beta is ad-hoc signed, not Apple-notarized; macOS may
   require **Privacy & Security → Open Anyway** for an official download.
4. Update the iPhone companion separately to
   [Lumi Remote 0.1.1](https://github.com/victorblanco-tech/lumi/releases/tag/lumi-remote-v0.1.1).

Back up Lumi before updating. Existing Production Library data, Lumi phrases,
lighting mappings and settings are retained. Dev and RC data remain separate.
A first Production installation starts empty; the installer contains no
personal tracks, USB registrations, show configuration or pairing credentials.

The checksum and SPDX component inventory are attached. Lumi Remote uses
Xcode and your own Apple Account on a physical iPhone; **there is no TestFlight
invitation or App Store release yet**. The Pro DJ Link Simulator remains an
independent product; its current production release is 0.4.0.

## Beta notes

- Recheck changed beatgrids/audio and prepared phrases before a show. Initial
  scan counts can change after full synchronization verification.
- Registering writable USB media may add a tiny `.lumi-media.json` identity
  file. Rekordbox databases, analysis and music are not modified.
- The preferred Editor waveform height can still reset after loading a track.
- The broader isolation/security audit is ongoing. Heavy Library operations
  should be completed before a show; new simulated checks are not a substitute
  for testing your own hardware and keeping manual lighting control available.
