# Lumi 0.5.0-dev-36

This development release finishes the Track Preparation Workflow polish:

- Ready for Show is a green check by default;
- an empty workflow queue is a calm `Nothing to review` state;
- tracks can protect Lumi phrase points, roles and Autoloop choices;
- protection is enforced in the engine and survives restart;
- trusted USB beatgrid/source updates remain allowed and reviewable.
