# Lumi 0.6.0-dev-12 / Lumi Remote 0.1.0-dev-12 – clock-safe Live motion

This development release removes the periodic iPhone Live pause exposed by the
physical dev-11 test. The waveform renderer itself was not the cause and is
unchanged.

The Mac and iPhone have independent wall clocks. Dev-11 correctly retained the
canonical Pro DJ Link observation time, but sent that Mac timestamp directly to
the iPhone. The iPhone then compared it with its own wall clock. Even a small
clock difference could make a fresh anchor appear old enough to exhaust the
750 ms stale-data guard before the following update, producing the visible
stop-and-catch-up pattern.

Every transport anchor now carries both its source observation time and its Mac
publication time. The iPhone derives only the source-side age from those two
values and applies that age to its own receipt time. Raw Mac timestamps remain
separate for strict stale/reordered-frame rejection; visual interpolation uses
only the translated local timestamp.

## Safety boundary

- the RGB waveform raster, color curve and resolution are unchanged;
- the fixed 22% Live playhead and 40-bar zoom contract are unchanged;
- the macOS waveform renderer is unchanged;
- no Pro DJ Link input, Light Plan, SoundSwitch MIDI or Ableton Link scheduling
  path changed;
- Remote interpolation remains presentation-only and never feeds back into the
  autonomous engine or show-critical output lanes.

## Verification

- Rust validates that publication time cannot precede source observation time;
- Swift deterministically tests a Mac/iPhone clock mismatch for both a snapshot
  and a later transport anchor;
- engine, Pro DJ Link input, Remote protocol and all Apple package tests pass;
- the complete Apple fast verification gate passes;
- the packaged Mac dev-12 app followed the LAN CDJ simulator and served the
  connected physical Remote;
- the signed Remote dev-12 build installed on aiVoon and restored its existing
  pinned-TLS Controller session;
- a 20.951-second physical `Animation Hitches` trace during live playback
  recorded zero hitches and zero potential interaction delays above 33 ms;
- after the trace startup second, the display delivered 53–60 surfaces every
  second, with no periodic low-cadence second.
