# 0.5.2-dev-7 – Pro DJ Link player identity

This development release replaces Lumi's invented Deck A/B labels with the
numbered identity DJs see on Pro DJ Link equipment.

## Changes

- Live and empty surfaces render `PLAYER 1`, `PLAYER 2`, and so on;
- a connected player's exact announced hardware model, such as `CDJ-1500X`, is
  shown beneath its player number;
- Local Playback uses the same numbered Player terminology;
- hardware model is optional presentation metadata and cannot affect player
  identity, transport timing, Light Plans or SoundSwitch output;
- older compatible snapshots and unavailable model metadata remain valid.

## Evidence

- Rust regression for exact player-number-to-device-model association;
- Swift strict-decoder regression for present and absent model metadata;
- complete Rust and Apple gates including native visual evidence.
