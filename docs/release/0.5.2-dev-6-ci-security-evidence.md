# 0.5.2-dev-6 – CI and security evidence

This development release strengthens the public-repository gates without
returning to a full macOS build on every development push.

## Changes

- `LumiEngineClient` tests are now part of the fast Apple development gate;
- vulnerability and release-license auditing have a dedicated weekly/manual
  Linux workflow and do not run on ordinary pushes or pull requests;
- the SPDX inventory is checked for missing declared licenses and for Lumi's
  separately packaged beat-link, Carabiner/Ableton Link and SQLCipher runtime;
- repository structure checks prevent the expensive audit from being attached
  to normal push or pull-request events.

## Evidence

- CI classification and repository structure regressions;
- complete local Rust and Apple gates;
- local RustSec, Maven OSV and release-license inventory audit.
