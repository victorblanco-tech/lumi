# Lumi 0.6.0-dev-10 / Lumi Remote 0.1.0-dev-9 – Remote hardening

This iteration makes the native iPhone Remote connection lifecycle deterministic
without changing any Pro DJ Link, Ableton Link or SoundSwitch execution lane.
Repeated Bonjour callbacks no longer reconnect a healthy client. Real service
replacement, app suspension and network loss advance a connection generation,
close the old pinned-TLS transport and prevent its late frames or command errors
from affecting the replacement session.

The isolated gateway now also applies finite deadlines to LAN writes and
gateway-to-engine command handoff. A phone that stops reading cannot occupy one
of the bounded client permits indefinitely. A four-client stress regression
publishes 20,000 alternating Player anchors and proves that each client retains
only the newest anchor per Player with contiguous outbound sequence numbers.
Installing a newer Lumi bundle also replaces an already enabled older gateway
automatically while retaining the durable paired-device state. Ad-hoc signed
Dev upgrades receive one bounded re-registration when macOS initially rejects
the refreshed helper against a stale launch constraint.

The accepted compact landscape design remains compact, but every primary mode
and offset control now has a 44-point touch target. Accessibility Dynamic Type
uses a roomier two-row top bar, and VoiceOver receives explicit status, value
and action descriptions for PDL, Light Output, Ableton Link, show mode and
lighting offset.

This is development evidence, not the physical-iPhone beta gate. Real iPhone
Local Network permission, two-device Controller transfer and the combined booth
soak remain required before external TestFlight distribution.
