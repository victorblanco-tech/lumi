# Lumi 0.5.1 — Public Beta

Lumi 0.5.1 is the first public-distribution build of Lumi's complete USB-to-show
workflow. It is functionally identical to 0.5.0 and adds the documentation,
legal notices, corresponding third-party source and expanded software bill of
materials required for a responsible public release.

Lumi turns a Rekordbox-prepared USB library into editable Lumi phrases and
deterministic SoundSwitch lighting decisions, then follows real Pro DJ Link
decks or Lumi's local players during a show.

This is a Public Beta. It has been validated intensively on the reference setup,
while field testing on other compatible Mac, USB, player, mixer and SoundSwitch
combinations is still required. Back up, dry-run and retain manual lighting
control before using Lumi during a show.

## Highlights

- **USB-first Library** — trust distinct OneLibrary USB devices, browse their
  real playlist hierarchy, review changes and synchronize selected playlists
  without modifying the source media.
- **Track preparation** — verify imported beatgrids, RGB waveforms and Hot Cues;
  edit Lumi-owned phrases; protect finished work; and use configurable queues.
- **Live Decks and Local Playback** — use the same Library analysis with real
  players or a dry-run local workflow, including master handoff, Hot Cue and
  Beat Jump recovery.
- **Isolated show lanes** — Pro DJ Link observation, Ableton Link BPM relay and
  SoundSwitch MIDI output run independently from UI rendering.
- **Light Plans** — combine Phrase Role, Track Color, Theme eligibility,
  variation and repeat protection into a plan compiled before playback.
- **SoundSwitch output** — map four banks with 32 AutoLoops each, learn and test
  MIDI signals through the Virtual Controller, and map Static Looks.

## Clean production installation

The production app uses bundle identifier `co.victorblan.tech.lumi` and stores
its database in `~/Library/Application Support/Lumi`. A fresh installation has
no tracks, trusted USB identities, personalized mappings or user-authored
phrases. Dev data is isolated and is never copied into Production automatically.

Upgrading an existing 0.5.0 Production installation to 0.5.1 preserves its
Production database; the patch contains no schema or data migration.

## Installation

1. Download `Lumi-0.5.1-arm64.dmg` and its `.sha256` file from GitHub Releases.
2. Verify the checksum.
3. Open the DMG and drag Lumi to **Applications - Lumi**.
4. If macOS blocks the unsigned build, follow the installation README included
   in the DMG.

## Requirements and limitations

- Apple Silicon Mac running macOS 15 or newer.
- Rekordbox OneLibrary USB media for the supported import workflow.
- SoundSwitch is required for the current lighting-output profile.
- Pro DJ Link hardware is optional when using Local Playback.
- The build is ad-hoc signed and not notarized. No paid Apple Developer account
  is required, but macOS displays an initial security warning.
- iPhone Companion and automatic color override output are not included in
  0.5.1.
