Lumi for macOS - public beta
===========================

This Apple Silicon build is distributed outside the Mac App Store and is
not signed with a paid Apple Developer ID.

Install
-------

Keep installed channels in these locations so they can coexist with separate
data and preferences:

- Production: /Applications/Lumi/Lumi.app
- Dev: /Applications/Lumi/Dev/Lumi Dev <version>.app
- RC: /Applications/Lumi/RC/Lumi RC <version>.app

1. Finish any active show and quit Lumi.
2. Open Install Lumi.pkg in this disk image and follow macOS Installer.
   The installer creates the correct channel folder automatically. No dragging
   or manual folder creation is needed. Administrator approval may be required.
3. Eject this disk image and open Lumi from the channel folder above.
4. If macOS blocks the installer or app, open System Settings > Privacy & Security.
5. For the verified official download, choose Open Anyway and confirm Open.

Only the application is installed or replaced. Existing tracks, phrases, MIDI
mappings, preferences and other channels are not reset or imported. On a Mac
without existing Lumi data, the production app starts with an empty library.

The three channels use distinct bundle identifiers and Application Support
directories. Installing or removing one app does not replace another channel's
database.

Only use a disk image downloaded from the official Lumi GitHub repository and
compare its SHA-256 checksum with the checksum published beside the release.

Requirements
------------

- Apple Silicon Mac
- macOS 15 or newer
- Local Rekordbox/SoundSwitch integrations remain optional

This build runs fully locally and has no runtime internet dependency.
