# Lumi `0.4.0-dev-54` — isolated realtime integration lanes

Dev-54 removes the shared Pro DJ Link source backlog that caused progressively
late UI, Ableton Link BPM and SoundSwitch AutoLoop output under CDJ-1500X load.

## Delivered

- bounded ordered critical ingress for Beat, load, master, play and confirmed
  transport changes;
- latest-value tempo, transport and display mailboxes per deck;
- source traffic class and bridge queue age on the versioned wire contract;
- a dedicated CdjStatus-derived tempo message for Ableton Link;
- rejection of older master-tempo observations and no Link correction for
  repeated unchanged Beats;
- engine-owned 5 ms integration processing, independent from SwiftUI;
- exactly-once AutoLoop acceptance for forward/backward landings and stale
  duplicate bursts.

## Verification

- Java bridge tests and 50,000-sample coalescing benchmark pass;
- complete Rust engine and Pro DJ Link suites pass;
- technical gate passes, including bounded 10,000-track snapshots and release
  snapshot performance;
- functional gate passes, including every Swift package and localization check;
- 15-second realtime MIDI soak: p50 69 µs, p95 10.045 ms, p99 10.060 ms, zero
  saturation;
- network pitch test: exact `155.000 -> 161.510 -> 151.900` convergence without
  an old-value regression;
- network transport test: one output after each forward/backward landing and
  none from the delayed duplicate burst;
- native headed test: Lumi Live Decks followed `90s Bitch`; SoundSwitch showed
  `1 Link · 161.5` and `1 Link · 151.9`; switching foreground applications did
  not interrupt output; explicit shutdown left no Lumi Link peer.

## Scope boundary

This is an unsigned Apple Silicon development build. It is not an RC. The
explicit transport/offset matrix and one-hour physical Wi-Fi/Ethernet soak stay
open in Epic 5.
