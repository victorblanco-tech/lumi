# Lumi 0.5.0-dev-27 — Live Decks fault containment

This development build closes the second planner failure that could restart
the engine and return the UI to Local Playback after a fresh Mac login.

## Root cause

The deck and Library adapters correctly matched the live tracks, but one loaded
track had no enabled Theme that could resolve every phrase to a physical
SoundSwitch AutoLoop. That is a valid, incomplete Light Plan configuration.
The condition was still represented as a process-level error, so launchd
restarted the engine with Local Playback as its safe default.

## Runtime behavior

- Pro DJ Link transport and deck hydration remain available.
- No Theme or AutoLoop is guessed when the mapping is incomplete.
- The affected track receives no automatic lighting plan until an enabled
  Theme fully resolves it.
- Other loaded tracks and their valid plans remain available.
- The realtime engine no longer exits for this content-level condition.

## Verification

- Unit regression: a track with no executable Theme fails closed without an
  engine error.
- Unit regression: a physically executable but policy-disabled Theme also
  fails closed without an engine error.
- Full engine suite: 86 passed, 3 hardware-dependent tests ignored.
- Installed-data reproduction: both connected decks remained ready and 3,573
  Pro DJ Link frames were processed without a restart.
