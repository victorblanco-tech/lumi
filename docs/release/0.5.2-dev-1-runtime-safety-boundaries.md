# 0.5.2-dev-1 – Runtime safety boundaries

Status: development evidence · 2026-08-31

This is the first bounded hardening increment after Public Beta 0.5.1. It does
not change the show workflow or migrate Production data.

## Delivered

- local engine connections and requests have explicit deadlines;
- a timeout closes the connection and releases the serialized request lease;
- Lumi verifies the executable identity before signalling a recorded process;
- current physical USB evidence wins over labels and legacy source metadata;
- independent equal-model USB devices receive distinct composite identities;
- the isolated USB worker validates the observed physical identity before it
  reads or writes Lumi state;
- regression tests cover silent IPC peers, stale process metadata, legacy USB
  migration and modern source non-rebinding.

## Compatibility

- domain, planning, MIDI and persisted library contracts are unchanged;
- 0.5.1 Production data is opened in place only by the Production channel;
- Dev keeps its separate data root and never alters a mounted USB source;
- changing a USB volume name or replacing/reformatting media can require
  explicit authorization instead of silently joining source histories.

## Verification

- Rust workspace tests and clippy gate;
- Swift package regressions, including an authenticated real-engine exchange;
- documentation and repository consistency checks;
- full macOS application build and visual evidence gate.
