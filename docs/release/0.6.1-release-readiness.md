# Lumi 0.6.1 release readiness

## Release identity

- Lumi version: `0.6.1`
- compatible Lumi Remote version: `0.1.0` (unchanged)
- status: Public Beta
- macOS channel: Production
- macOS bundle identifier: `co.victorblan.tech.lumi`
- macOS data: `~/Library/Application Support/Lumi`
- platforms: Apple Silicon macOS 15+ and iPhone iOS 18+

## Scope and isolation

0.6.1 repairs the macOS client, persistent engine and Remote Gateway control
plane after a long-running headed session exposed connection exhaustion. It
does not change the Pro DJ Link ingestion, exactly-once SoundSwitch MIDI output
or isolated Ableton Link relay algorithms.

There is no schema reset. A Production upgrade preserves the existing library
and configuration; a clean Production install remains empty. The DMG contains
no tracks, authored phrases, trusted USB identities, output mappings or remote
pairing credentials.

## Acceptance evidence

- Rust real-process testing covers partial-frame disconnect and reconnect.
- Swift tests distinguish retryable transient connection failures from
  non-retryable credentials, protocol and service-approval failures.
- Headed Dev testing proved that the same open window reconnects after a forced
  engine replacement while the Remote Gateway retains its admin socket.
- A playlist-driven, two-Player simulator soak ran with Lumi in `Start` and
  SoundSwitch open. Repeated Master/on-air/transport handoffs remained
  exclusive and coherent while new USB tracks were preloaded automatically.
- During observed checkpoints, Lumi remained `Ready`, live and next tracks had
  valid phrase and AutoLoop plans, SoundSwitch followed the active BPM using
  exactly one Link peer and the simulator reported no Pro DJ Link traffic
  error.
- A stale phrase-warning presentation issue was observed and recorded as a
  non-blocking known limitation; authoritative deck state, planning and output
  remained healthy and the message later cleared without intervention.

## Product publication contract

Only the exact release commit receives `v0.6.1`. That tag creates the controlled
macOS draft with DMG, SHA-256 checksum and SPDX SBOM. The artifacts are reviewed
before the release is published.

Lumi Remote remains at its existing independent `lumi-remote-v0.1.0` release;
there is no new iOS tag or duplicate validation artifact for this patch. Pro DJ
Link Simulator `0.4.0-dev-56` is already available as a separate prerelease and
served only as release acceptance infrastructure.

The macOS app remains ad-hoc signed and intentionally not notarized.
