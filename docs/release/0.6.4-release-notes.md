# Lumi 0.6.4 — Public Beta

Release preparation; not published yet.

This update brings the USB preparation workflow and live show operation closer
together, with clearer source identity, playlist selection and service status.

## USB sync and track preparation

- Keep two USB sticks distinct, including same-model devices with duplicate FAT
  volume identifiers.
- Identify trusted media through read-only network discovery on supported
  Players. Show the inserted USB separately from the loaded track's source,
  including tracks loaded through another Player over LINK.
- Preserve a confirmed, still-loaded track and its plan when its source USB is
  safely ejected; do not confuse that cached track with a newly inserted stick.
- Browse playlist folders, retain sync selection and see source-specific sync
  progress and failures. Review changed tracks individually or in bulk.
- Keep library browsing work separate from the realtime show processing.

## Live operation

- Prepare upcoming phrase commands independently of the output offset.
- Optionally start the show at a phrase boundary, with the launch state visible
  in the controls. SoundSwitch is triggered once; Lumi does not continuously
  correct its playback phase.
- Handle loop returns and reordered beat messages without manufacturing a
  growing position lead or replaying completed cues.
- Improve service start, stop and shutdown reporting, and tempo-only Link
  recovery. Reuse unchanged waveform projections without changing their colors.
- Update Jackson and rustls to address known dependency vulnerabilities.

## Important live-show limitation

The accepted hardware baseline uses **Ethernet, Wi-Fi off, and the macOS
application firewall temporarily off**, with a zero lighting offset. The owner
confirmed on-time phrase transitions and repeated start tests with real CDJs
and SoundSwitch lighting. This is not a guarantee for other hardware/networks.

On the reference Mac, a controlled firewall-on/off/on comparison reproduced
packet delivery delays and reordering with the firewall enabled. Reliable live
timing with the firewall enabled and over Wi-Fi remains unresolved.

If choosing this temporary show configuration, use a trusted, preferably
isolated DJ network. A network with an internet or venue uplink is not isolated.
Disabling the firewall reduces protection; do not use this workaround on public
or untrusted networks. Restore the firewall immediately after the show. Lumi
does not change firewall settings or system permissions automatically.

## Installation and data

The production installer updates `/Applications/Lumi/Lumi.app` and retains the
existing Production library and preferences. It does **not** import Dev data
automatically. Make a backup before upgrading. A separately authorized local
Dev-to-Production transfer is not bundled in the public installer.

The release contains no personal library, music, MIDI mappings or USB identity
files. It remains an Apple Silicon public beta, distributed outside the App
Store without Apple notarization. Follow the normal installation guide.

Lumi Remote and the simulator retain independent releases. They are not
automatically promoted by this Mac release preparation.
