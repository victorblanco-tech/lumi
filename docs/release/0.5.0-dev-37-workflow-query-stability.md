# Lumi 0.5.0-dev-37

This development release hardens the Track Preparation Workflow after headed
testing with the real Dev library.

## Fixed

- Workflow buttons now derive their selected presentation from the same
  authoritative query that produced the visible rows.
- A Library query retains its serialized exchange until its bounded page is
  decoded and published. Monitoring or a track mutation can no longer overtake
  the response and leave a `Changed after USB sync (0)` label above
  `Not Started` rows.
- `Protect Phrases` retains one label and width in both states. Its previous
  conditional information banner was removed, so the waveform and editor do not
  move when protection changes.
- The browser mode control keeps a fixed height and workflow queues use their
  own bounded scroll area. The split divider can no longer cover or compress
  the first `Changed after USB sync` action.
- The Swift filter now sends the exact protocol identity
  `changedAfterUsbSync`; the previously synthesized acronym spelling was
  rejected by the engine and left the prior page visible.

## Safety

- No Pro DJ Link, Ableton Link, planner or MIDI output lane changed.
- Phrase protection remains enforced in the engine.
- USB analysis and explicit source review remain available while protected.

## Verification

- Full Rust, Swift and native macOS gates.
- Exact engine regression for an empty workflow query followed by phrase
  protection.
- Headed desktop acceptance against the installed Dev application.
