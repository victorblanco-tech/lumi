# Lumi 0.5.0-dev-7 — explicit Theme Strategy

Date: 2026-08-22

This development build makes the relationship between SoundSwitch Banks and Lumi
Themes explicit and selects one coherent Theme per automatically compiled track.

## Test focus

1. Open `Light Plans → Theme Strategy` and confirm all four Bank names match
   `Integrations → Lighting Outputs → Banks & AutoLoops`.
2. Keep at least one Theme enabled, choose a fallback and save the strategy.
3. In Plan Preview leave Theme at `Automatic · Theme Strategy`; confirm every
   phrase uses the selected Bank.
4. Give one Theme Track Color `Only`, select one Rekordbox color and preview a
   matching and non-matching track.
5. Load two tracks in Local Playback and confirm Theme cooldown keeps the current
   and prepared next track from selecting the same Theme when another complete
   Theme is available.
6. Confirm AutoLoop and verified Static Look output still occur only at their
   compiled transitions.
