# Epic 1 – 0.1.0 release evidence

Status: development milestone `0.1.0-dev`; not a signed production release.

## Reproducible gate

From a clean checkout, one command performs the environment and version audit,
architecture checks, JSON validation, locked Rust formatting/lint/tests/build,
the 200-phrase release performance test, Swift warnings-as-errors package
tests, the real Swift-to-Rust process scenario, unsigned Apple Silicon app
build, and deterministic dark/light PNG rendering:

```bash
./scripts/verify.sh
```

Rust is pinned in `rust-toolchain.toml`; Cargo dependencies are pinned in
`Cargo.lock`; CI uses the stable Apple Silicon `macos-26` runner. New Rust and
Swift warnings, including deprecations, fail the gate.

## Fault and performance summary

- malformed envelopes return a typed `invalidEnvelope` response while the
  session remains usable and OFF;
- stale plan and state revisions are rejected and report the authoritative
  revision without mutation;
- real bounded-queue saturation raises a diagnostic, forces LIVE to PAUSED,
  confirms the output gate closed, and cannot create a provider call;
- stale output work is revalidated immediately before the provider and is
  recorded as skipped rather than executed;
- client disconnect terminates the app-scoped engine; stopped transport rejects
  later commands;
- a 200-phrase release-mode plan is required to complete within 50 ms;
- 16× and 64× playback produce the same semantic cue order, while the full 64×
  fixture reaches beat 128 with all four phrase actions recorded.

## Architecture and scope audit

`scripts/check-architecture.sh` rejects forbidden dependency directions for the
pure domain, wire protocol, planner, simulator, output port, DesignSystem, and
SwiftUI feature package. `scripts/check-structure.sh` rejects ambiguous utility
directories and verifies all canonical evidence is present.

The final exact merge commit, successful GitHub Actions run, and P0/P1 issue
audit are attached to GitHub issue
[#20](https://github.com/victorblanco-tech/lumi/issues/20) after the green release
gate. Signing, notarization, LaunchAgent installation, live providers, iPhone,
and Windows remain explicitly outside Epic 1.
