# Lumi 0.6.1 — Public Beta

Lumi 0.6.1 is a focused stability update for long-running Live Decks sessions.
It keeps the macOS interface, persistent engine and optional iPhone gateway
connected without changing the isolated Pro DJ Link, SoundSwitch MIDI or
Ableton Link show lanes.

## Highlights

- **Long-session reconnect stability** — an open Lumi window now makes bounded
  recovery attempts after a local engine socket replacement instead of losing
  both Live Decks.
- **Bounded gateway health** — Remote Gateway health checks reuse one
  authenticated localhost connection rather than repeatedly opening and
  cancelling sockets.
- **Safe failure handling** — unexpected authenticated client I/O failure parks
  operation, Link and lighting output before the persistent engine accepts a
  replacement UI connection.
- **Production-path soak evidence** — two playlist-driven simulated Players
  completed repeated Master handoffs while Lumi remained in `Start`, generated
  live and next-track phrase plans, drove SoundSwitch AutoLoops and maintained
  one Ableton Link peer without Pro DJ Link traffic errors.

## Compatible product set

- Lumi for macOS: **0.6.1**
- Lumi Remote for iPhone: **0.1.0**
- Optional development test tool: **Pro DJ Link Simulator 0.4.0-dev-56**

Lumi Remote retains its independent version because this patch does not change
the iPhone application or its public protocol. The simulator is distributed in
a separate prerelease and is not installed with Lumi.

## Data safety and upgrading

Installing 0.6.1 over 0.6.0 preserves the Production library, authored phrases,
trusted USB sources, SoundSwitch mappings and Light Plan configuration in
`~/Library/Application Support/Lumi`. The release DMG contains no personal
tracks, USB identities, mappings or pairing credentials.

Back up important Lumi and rekordbox data before upgrading. Keep manual
lighting control available while using any Public Beta during a show.

## Installation

1. Download `Lumi-0.6.1-arm64.dmg`, its checksum and SBOM from this release.
2. Verify the SHA-256 checksum.
3. Open the DMG and drag Lumi to **Applications - Lumi**.
4. Follow the installation README in the DMG if macOS blocks the unsigned app.
5. Lumi Remote 0.1.0 users do not need to reinstall the iPhone app for this
   patch.

## Known beta limitation

After an unavailable phrase analysis, its warning can occasionally remain
visible briefly after a newly active Master already has a valid phrase plan.
The live plan and lighting execution continue correctly; the message clears on
a subsequent state refresh. This is a presentation-state issue recorded for a
later update.
