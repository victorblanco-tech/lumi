# Lumi 0.5.0-dev-34

This Dev release introduces the first visible Track Preparation Workflow while
preserving the isolated show-critical runtime.

## Included

- `Not Started`, `In Progress` and `Ready for Show` per track;
- a `Changed after USB sync` inbox with exact change reasons;
- preparation/workflow navigation beside Playlists;
- editor status control and explicit review completion;
- revision-safe SQLite schema 16 persistence and paged workflow queries;
- preservation of Lumi phrase points after source analysis changes.

## Safety

Workflow commands only mutate Library state. They do not revise a Live Plan,
send MIDI, change Ableton Link, join Pro DJ Link or enter the realtime executor.

## Deferred

- configurable user-defined workflow steps and rule builder;
- guided edit/mashup version replacement and phrase reuse;
- mobile workflow controls.
