# Lumi 0.6.0-dev-9 / Lumi Remote 0.1.0-dev-8 – fixed Live viewport

The Master waveform now keeps its playhead at the same 22% screen position for
the entire track on macOS and iPhone. At the first and last bars the viewport
uses black pre-roll or post-roll instead of clamping to the track and moving the
playhead.

The Remote Master uses the same 40 visible bars in portrait and landscape.
Rotation only changes the two-Player composition and available pixel density;
it does not silently change the musical zoom level. Track Editor, manual Live
inspection and the prepared Player overview keep their existing bounded
navigation behavior.

Regression coverage verifies the start, middle and end positions and ensures
that waveform sampling outside the real track remains empty.

The Remote header now keeps `PDL`, `LIGHT` and `LINK` visible while discovery
or reconnection is in progress. Their unavailable state is shown neutrally;
stale green health is never implied and controls remain disabled until the
authenticated session returns.

Remote track changes carry the complete 16,384-point RGB asset losslessly in a
compact static projection. The iPhone draws that exact asset with the same
one-pixel normalized RGB line treatment as the Mac. The packed wire form keeps
two full Player waveforms inside the fixed 512 KiB frame. The 20 Hz position/BPM
anchors remain separate and small, so visual detail does not enter the Pro DJ
Link, Ableton Link or lighting timing lanes.
