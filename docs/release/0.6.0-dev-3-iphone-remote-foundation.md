# Lumi 0.6.0-dev-3 – iPhone Remote foundation

This development increment starts Epic 9 without enabling an unfinished remote
on the LAN or changing the existing Mac show-critical runtime.

## Included

- independent Lumi Remote `0.1.0-dev-1` native iOS product and release identity;
- accepted iPhone Live design and isolated Remote Gateway architecture;
- scoped, bounded Remote v1 contract with shared Rust/Swift fixtures;
- actual engine snapshot conversion test with no Library, USB, audio path or
  engine credential leakage;
- bounded projection queues, visual-anchor coalescing and contiguous per-client
  delivery sequencing;
- release-channel Bonjour discovery and trust validation;
- one-use pairing registry, rate limiter and channel-scoped Keychain storage;
- revision-safe command model, single Controller lease and idempotency ledger;
- native portrait/landscape Live UI foundation with RGB waveform, beatgrid, Hot
  Cues, phrases, Light Plans, future-cue sheet and booth controls;
- independent draft-release automation for Lumi Remote and the Pro DJ Link
  Simulator.

## Deliberately not enabled

- no LAN listener before pinned TLS and persistent Mac trust exist;
- no remote command reaches the engine yet;
- no production pairing UI or physical iPhone build is claimed;
- no Local Playback, Library, USB Sync or Track Editor exists on iPhone;
- no current Pro DJ Link, SoundSwitch MIDI or Ableton Link behavior is changed.

## Verification boundary

The Rust Remote crates and Swift Remote packages have deterministic unit and
contract tests. The iOS target builds for a generic Simulator. Physical iPhone,
Bonjour permission, pairing, lifecycle, accessibility and combined show-load
acceptance remain required before beta delivery.
