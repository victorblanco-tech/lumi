# Lumi 0.4.0-dev-51 — exactly-once AutoLoop output

Dev-51 replaces the predictive lighting-output path with one deterministic
phrase executor. SoundSwitch receives a discrete Bank selection when required
and one configured AutoLoop selection; SoundSwitch then owns playback.

## Included

- explicit exactly-once execution identity and state machine;
- immediate current-phrase selection when Lumi enters Start;
- no periodic, progress, seek-correction or BPM-driven AutoLoop retriggers;
- canonical playing transport advanced by exact Pro DJ Link Beat packets;
- status and precise-position confirmation without duplicate loop generations;
- Live metadata and waveform driven by one monotone visual clock;
- honest **Saved** labelling for lighting offset until scheduled deadlines ship
  in dev-52;
- Apple Silicon development DMG, ad-hoc signed.

## Verified

- 65 engine unit tests: 63 passed and 2 hardware-dependent tests ignored;
- 40 Pro DJ Link tests passed;
- 52 Live workspace tests passed;
- Pro DJ Link Java bridge build and test passed;
- real Player 1 and Player 2 plus DJM-V5 discovery over Wi-Fi;
- real SoundSwitch selections for the current Intro and Bridge phrases;
- 0 duplicate, 0 late and 0 saturated AutoLoop executions in the final run;
- MIDI dispatch p95: 132 microseconds;
- 251-sample physical loop trace: one `192 -> 65` loop produced exactly one
  revision and one discontinuity, with zero backwards jitter.

## Deferred

- scheduled negative/positive lighting offset;
- the complete hotcue, beatjump, pause/resume and master-handover matrix;
- the one-hour combined Wi-Fi release soak.

Those remain the explicit scope of E5-03 and E5-04. Dev-51 is not an RC.
