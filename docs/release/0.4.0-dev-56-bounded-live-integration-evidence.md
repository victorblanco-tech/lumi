# Lumi `0.4.0-dev-56` — bounded Live integration evidence

Dev-56 completes the software scope of Epic 5 and makes the remaining shared
engine handoff measurable. It does not weaken the requirement for the final
physical and one-hour release evidence.

- Pro DJ Link source age now includes both Java bridge queue residence and the
  Rust supervisor queue;
- a constant-space histogram reports p50, p95, p99, maximum and sample count;
- fresh Link clock observations leave the 5 ms engine coordinator before
  library hydration or lighting-plan reduction;
- the native Integration diagnostics expose source age alongside queue depth,
  high-water, coalescing and critical saturation;

  realtime MIDI-only and combined lanes;

## Installed desktop acceptance

The packaged Apple Silicon app was installed from the generated DMG without
replacing the existing Dev database. The native Lumi and SoundSwitch UIs then
passed the connected simulator flow:

- `Off -> Arm -> Start` selected the current `INTRO BLUE PINK` AutoLoop
  immediately instead of waiting for the next phrase;
- a live landing in `BD BRIDGE` selected `BD BRIDGE BLUE PINK`, and a second
  hotcue-like landing in `DROP` selected the planned Drop AutoLoop exactly
  once;
- master pitch changes propagated `155.0 -> 161.5 -> 151.9` to SoundSwitch
  through one Link peer;
- BPM and AutoLoop output continued while SoundSwitch was foreground and Lumi
  was not being polled;
- Pause, a position landing and Start reasserted only the current AutoLoop;
- final diagnostics reported zero late AutoLoop output, zero queue saturation,
  zero provider failures and Pro DJ Link source p95 of 10.0 ms;
- UI Quit removed the Link peer inside the cleanup window while the same
  launchd engine PID remained safely parked with only its localhost listener;
  reopening the app reattached to that engine and restored the configured
  auto-start behavior.

SoundSwitch Performance playback must be active for its AutoLoop progress to
run. This is a receiver precondition, not a Lumi timeline responsibility.
