# Lumi 0.5.0-dev-26 — Live Decks planner safety

This development build fixes a restart loop that made the Live Decks selector
fall back to Local Playback after a recognized CDJ track was loaded.

## Root cause

Lumi correctly reduced the global Light Plans policy to the Themes that were
actually executable for the loaded track. A track with only one executable
Theme could, however, leave no eligible selection when that Theme was marked
`Color only` for a different Rekordbox color. The resulting planner error
terminated the engine; macOS restarted it with Local Playback as its default.

## Runtime behavior

- A globally valid creative policy can no longer make a playable track fatal.
- When the track-specific executable subset has no color-eligible candidate,
  Lumi selects its subset-aware default Theme.
- Matching `Color only`, `Prefer`, rotation and cooldown behavior remain
  unchanged whenever eligible alternatives exist.

## Verification

- Planner regression: one executable Theme, non-matching `Color only` rule.
- Engine regression: the complete Light Plans policy is projected onto a
  one-Theme executable catalog and still produces a ready plan.
- Live validation: select Live Decks, receive recognized CDJ input and confirm
  the engine remains active without a launch-service restart.
