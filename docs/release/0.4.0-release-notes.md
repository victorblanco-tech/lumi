# Lumi 0.4.0

Status: **Stable owner release**  
Date: **2026-08-18**

Lumi 0.4.0 is the first release built around a direct, read-only Pro DJ Link
input and isolated show-critical integration lanes. It has been accepted on a
physical two-player CDJ-1500X, DJM-V5, SoundSwitch, Control One and DMX setup.

## Highlights

- trusted Rekordbox One Library USB sources with playlist-level sync, change
  impact, device identity, track provenance and safe library rebuilds;
- direct Pro DJ Link discovery and live transport for players and mixers;
- library-backed RGB waveforms, beatgrids, Hot Cues and Lumi-owned phrases in
  Track Editor, Local Playback and Live Decks;
- deterministic phrase and AutoLoop planning for both loaded decks;
- exactly-once SoundSwitch Bank/AutoLoop MIDI output on phrase changes, starts,
  Hot Cues and Beat Jumps;
- isolated Ableton Link BPM relay that follows the master deck and pitch slider
  without receiving phrase, lighting or UI state;
- launchd-owned local engine with stable CoreMIDI endpoints and reconnectable
  native macOS UI;
- separate Production, RC and Dev applications, preferences and databases;
- atomic data backup, creative archive and clean library rebuild support.

## Physical acceptance

The owner accepted the complete chain using two CDJ-1500X players, a DJM-V5,
SoundSwitch, Control One and lighting output. Master handoffs and pitch changes
remained synchronized, phrase AutoLoops triggered on the intended beat, and UI
navigation did not interrupt the realtime lanes. Starting player 2 during an
existing player-1 show preserved Pro DJ Link, Ableton Link and AutoLoop output.

A Beat Jump correctly cancelled the old forecast, selected the landing phrase
and triggered its AutoLoop on the next exact beat. Lumi may briefly show an
orange position-reacquisition message while independently confirming that
landing; this is a conservative diagnostic and did not interrupt output in the
accepted run.

## Install

Download the DMG and adjacent checksum from the GitHub release. Verify the
SHA-256 value, open the DMG and drag **Lumi** to its included Applications –
Lumi destination. Production is installed as:

`/Applications/Lumi/Lumi.app`

This owner release is ad-hoc signed and not Apple-notarized. macOS may require
the documented one-time **Open Anyway** action. The app is Apple Silicon-only,
runs fully locally and has no runtime internet dependency.

## Known limitations

- no iPhone companion app yet;
- no Windows build;
- public clean-Mac distribution is not notarized with a paid Apple Developer
  ID;
- a short, correctly recovered Beat Jump can temporarily show an overly severe
  orange exact-position message;
- formal multi-hour Wi-Fi/Ethernet release evidence remains useful before a
  broader public-user release, despite successful intensive owner testing.
