# Lumi 0.5.0-dev-28

This development release makes automatic Light Plan eligibility strict,
explainable and metadata-refresh safe.

## User-visible behavior

- A Theme configured as Track Color `Only` is selected only for a matching
  Rekordbox Track Color. There is no hidden last-resort override.
- A recognized deck without an executable plan remains connected and visible as
  `AUTO HELD`. The deck explains which Phrase Roles are missing per Theme or
  which Track Color condition excludes an otherwise complete Theme.
- A color-only change on a trusted OneLibrary USB is shown as a new metadata
  revision even if a previous review kept the same active analysis. Normal sync
  can promote the color without replacing Lumi phrases or Rekordbox analysis.

## Safety

The change stays outside the Pro DJ Link, Ableton Link and realtime MIDI lanes.
Incomplete configuration emits no automatic lighting command, never changes a
Phrase Role and never crosses Themes automatically.

## Current-library evidence

- `90s Bitch - Extended Mix` has no stored Track Color. Its only complete Theme
  is `BLUE PINK`, configured as Pink `Only`; Lumi therefore holds until the Pink
  USB metadata is synchronized or Theme Strategy changes.
- `My Favourite Regrets (Vic DJ Edit)` has no single complete Theme: `BLUE PINK`
  lacks `BD CHORUS 2`; `GREEN PINK` and `BLUE RED GREEN` lack `PRE DROP 1` and
  `PRE DROP 2`. Lumi shows those gaps instead of inventing a plan.
