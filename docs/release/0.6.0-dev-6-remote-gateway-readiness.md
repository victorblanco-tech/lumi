# Lumi 0.6.0-dev-6 – Remote Gateway readiness

This development build fixes the first headed Mac-to-gateway acceptance issue
found while enabling iPhone Remote from the packaged app.

## Fixed

- The Mac now decodes the lower-camel-case `Id` and `Sha256` field names emitted
  by the Rust Remote Gateway.
- Pairing approval, device revocation and Controller transfer use the same
  explicit field convention in both implementations.

## Evidence

- Rust admin serialization contract test;
- Swift service-record, status, device and invitation decoding tests;
- Swift invitation-approval request encoding test;
- protected loopback create-and-approve integration test.

The iPhone product remains `0.1.0-dev-3`; no iPhone wire or presentation change
was required for this Mac-local management fix.
