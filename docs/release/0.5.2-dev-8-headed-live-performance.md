# Lumi 0.5.2-dev-8 — headed Live performance

## Outcome

The actual packaged Dev application remains responsive after loading Local
Playback Players. The small metadata strip no longer uses a periodic SwiftUI
timeline that caused the complete two-Player and embedded Library layout to be
recomputed four times per second.

## Preserved architecture

- RGB waveform motion remains an independent Core Animation lane.
- Phrase and AutoLoop plan motion remains an independent Core Animation lane.
- Engine snapshots remain authoritative for transport changes and
  discontinuities.
- Pro DJ Link, Ableton Link and SoundSwitch output never depend on UI refresh.

## Regression protection

The architecture gate rejects a `TimelineView` in `LiveDeckSurface`. Headed
verification must load both Local Playback Players and confirm bounded UI CPU
before 0.5.2 is promoted.
