# Lumi 0.5.0-dev-5 — SoundSwitch Static Look mapping

## Outcome

Lumi now exposes SoundSwitch Static Looks beside Banks & AutoLoops under
`Integrations → Lighting Outputs`. The surface mirrors SoundSwitch's 32 global
slots in four columns, supports names, guided MIDI Learn and a direct toggle test.

The existing `Moving Heads OFF` and `Only Lasers` mappings are retained through
their Channel 12 / Note 64–65 addresses. Planning rules remain in Light Plans.

## Capability boundary

The physical POC proved that one learned pulse toggles a Static Look and that
SoundSwitch allows one selected Static Look at a time. SoundSwitch provides no
state feedback, so Lumi records activation and release verification separately.
Unverified resources cannot participate in automatic output.

This release does not claim automatic Static Look execution or Color Override
execution. Those remain fail-closed follow-up work after mapping verification.
