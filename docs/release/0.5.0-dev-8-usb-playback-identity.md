# Lumi 0.5.0-dev-8 — USB identity and playback locations

Date: 2026-08-22

This development build repairs duplicate trusted USB records caused by a changed
macOS volume UUID and makes USB-backed audio playable from any currently mounted,
synchronized copy.

## Test focus

1. Connect `DJ VIC GRAY` and open `Import & Sources`.
2. Expand GRAY, select the previously synchronized playlist and run Sync.
3. Confirm the duplicate GRAY trusted-source row is consolidated into one row.
4. Open Library and load a track other than `90s Bitch` in Track Editor.
5. Confirm Play starts audio from the mounted GRAY USB.
6. Confirm the existing `90s Bitch` phrases and all lighting configuration remain
   unchanged.

The consolidation deliberately fails closed when two same-named sources do not
resolve to the exact same complete canonical track set.
