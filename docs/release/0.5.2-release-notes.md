# Lumi 0.5.2 — Public Beta

Lumi 0.5.2 is a compatibility-preserving hardening release for the complete
USB-to-show workflow introduced in 0.5.0 and prepared for public field testing
in 0.5.1. It tightens runtime ownership, removes retired provider paths and
improves Live and USB reliability without automatically changing Production
data or user configuration.

## Highlights

- **Safer local runtime** — bounded engine-client operations, verified process
  ownership and predictable recovery replace indefinite or ambiguous control
  actions.
- **Supported providers only** — Live Decks uses direct Pro DJ Link and Import
  & Sources uses trusted Rekordbox OneLibrary USB media. Retired BLT, XML and
  direct local-Rekordbox product paths are removed.
- **Isolated USB work** — scanning and synchronization run through a supervised
  worker outside Pro DJ Link, Ableton Link and SoundSwitch MIDI lanes.
- **Exact USB presence** — two equal-model USB disks retain independent
  identities, and only physically mounted matching media appears connected.
- **Recognizable Players** — Live shows `Player 1`, `Player 2` and the announced
  hardware model such as `CDJ-1500X`.
- **Stable RGB Live surfaces** — bounded and detailed Library waveforms share
  the same saturated 8-bit RGB data, while cancelled renders cannot flash an
  older track or zoom level back into view.
- **Stronger quality gates** — engine-client, persistence, documentation,
  security, licence and packaging boundaries have broader automated coverage.

## Data safety and upgrading

The Production bundle identifier remains `co.victorblan.tech.lumi` and its data
remains in `~/Library/Application Support/Lumi`. Installing 0.5.2 over 0.5.1
opens the existing Production database without importing Dev data. The DMG does
not contain tracks, trusted USB identities, personalized mappings, phrases or
configuration.

Back up important Lumi and Rekordbox data before upgrading. Keep manual
lighting control available while using any Public Beta during a show.

## Installation

1. Download `Lumi-0.5.2-arm64.dmg` and its `.sha256` file from GitHub Releases.
2. Verify the checksum.
3. Open the DMG and drag Lumi to **Applications - Lumi**.
4. If macOS blocks the unsigned build, follow the installation README included
   in the DMG.

## Requirements and known follow-up

- Apple Silicon Mac running macOS 15 or newer.
- Rekordbox OneLibrary USB media for the supported import workflow.
- SoundSwitch is required for the current lighting-output profile.
- Pro DJ Link hardware is optional when using Local Playback.
- The build is ad-hoc signed and not notarized.
- Physical acceptance found a possibly slower visible BPM-slider response than
  an earlier build. Integrations remained functional and this is not a 0.5.2
  blocker; `0.6.0` starts with separate measurements of Pro DJ Link ingestion,
  Link publication and SoundSwitch/UI refresh before optimization.
- iPhone Companion and automatic color override output are not included.
