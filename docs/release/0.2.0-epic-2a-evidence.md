## Performance budgets

The deterministic scale adapter generates exactly 10,000 synthetic tracks and
one 10,000-track playlist. The release-mode gate records all timings and fails
when any budget is exceeded:

| Operation | Budget |
|---|---:|
| Generate the 10,000-track canonical fixture | 1 s |
| Import into a migrated in-memory SQLite repository | 5 s |
| Read the last 50-row collection and playlist pages | 100 ms combined |
| Exact search across 10,000 tracks | 250 ms |
| Decode and present a bounded 50-row native Swift page | 100 ms |

These are regression budgets, not product marketing claims. The gate prints the
measured Rust timings to local and CI logs. Paging is capped at 200 records by
the engine contract and the native default remains 50, so a 10,000-result query
never creates 10,000 SwiftUI rows.

## Fault matrix

| Boundary | Injected failure | Required invariant |
|---|---|---|
| SQLite migration | incompatible pre-existing table | every attempted schema change rolls back |
| Analysis refresh | trigger abort during waveform write | the complete previous track remains byte-for-byte equivalent |
| Source reconcile | trigger abort during atomic track/timeline update | analysis and Lumi timeline both remain at their previous revisions |
| Reimport process interruption/legacy partial checkpoint | restart after one of three source changes, including an older prematurely advanced source header | source and playlists recover to the last complete checkpoint and the remaining diff is resumable |
| Audio preview | missing and corrupt local files, stale completion generation | analysis stays usable and stale audio work cannot replace current transport |
| Timeline/catalog concurrency | stale revision commands | explicit typed conflict with no mutation |
| Simulator queue | real bounded-queue saturation while LIVE | operation becomes PAUSED and no new output provider record is created |
| Engine protocol/process | malformed envelope, disconnect, missing helper, protocol mismatch | typed fail-closed error or clean process termination; output remains closed |

The Rekordbox parser/version/capability fault rows belong to E2A-00/E2A-02 and
cannot be truthfully certified before a disposable Rekordbox 7 library exists.

## Visual and architecture audit

`scripts/check-epic-2a-evidence.sh` requires the dark/light Library and editor,
Phrase Role settings/mapping, four-Theme matrix, reconciliation conflict, and
Library-backed Next-plan PNGs. The renderer uses fixed locale, dimensions,
appearance, key notation and fixture data.

`scripts/check-architecture.sh` keeps the canonical library free of SQL,
runtime and provider adapters; keeps the demo and SQLite adapters pointing
inward; prevents SoundSwitch/MIDI/bank/slot concepts from entering the logical
Autoloop catalog; and keeps Swift feature views independent from engine process
ownership. The simulator receives only normalized track identity and never
depends on SQLite, Rekordbox, SoundSwitch or DJ hardware.
