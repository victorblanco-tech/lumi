# Lumi 0.6.1-dev-1 – Long-session reconnect stability

This development build fixes a control-plane failure found during an extended
headed session with two CDJ-1500X Players and a DJM-V5.

## Fixed

- Remote Gateway health polling reuses one authenticated localhost connection
  instead of opening and cancelling a new socket every two seconds.
- A transient local engine connection failure is retried without retrying an
  invalid credential, protocol or service-approval failure.
- An open Lumi window makes several bounded recovery attempts after an engine
  socket replacement rather than remaining disconnected after one attempt.
- An unexpected authenticated client I/O failure parks operation, Link and
  lighting output safely before the persistent engine accepts a new UI.

The Pro DJ Link ingestion, Ableton Link relay and exactly-once SoundSwitch MIDI
execution lanes are unchanged by this repair.

## Verification

- Rust real-process partial-frame disconnect and reconnect regression;
- Swift transient-connect and non-retryable-authentication regressions;
- strict Swift compilation and product version validation;
- signed headed Dev validation with the physical Pro DJ Link devices.
