# 0.4.0-dev-45 — Position consensus and UI resume

## Problem

A physical CDJ-1500X run began smoothly, but switching focus from Lumi to
SoundSwitch left the waveform behind. Later the SoundSwitch AutoLoop scrubbed
and Hot Cue use made the instability worse. Diagnostics separated the paths:
the CoreMIDI realtime lane remained unsaturated with sub-millisecond dispatch,
while ordinary playback accumulated hundreds of false position
discontinuities and hard Ableton Link re-anchors.

## Decision

- Returning to Lumi restarts only its Core Animation layers from the existing
  read-only visual clock. No engine, Link or MIDI command is sent.
- One precise-position jump is never authoritative. Three consecutive samples
  must follow a coherent new timeline before Lumi advances the transport
  generation.
- Interleaved stale frames reset confirmation. A confirmed Hot Cue or loop wrap
  cancels the old realtime generation before applying the landing phrase.
- Beat packets remain the low-latency Link timing source; exact position remains
  the phrase and AutoLoop authority after jitter filtering.

## Automated evidence

- `cargo test -p lumi-prolink-input`
- `swift test --package-path apps/macos/Packages/LumiLiveWorkspace`
- exact Hot Cue regression confirms one new transport timeline only after
  stable position consensus;
- stale old-timeline interleaving cannot satisfy consensus;
- all LiveWorkspace presentation tests remain green.

## Physical acceptance target

Run the packaged build against the long Player-1 loop and SoundSwitch. Across
normal playback and repeated Lumi/SoundSwitch foreground switches:

- discontinuity count changes only at the real loop boundary or Hot Cue;
- hard Link re-anchor count changes exactly once per confirmed transport jump;
- AutoLoop realtime output remains unsaturated and below its dispatch budget;
- waveform and AutoLoop plan resume at the current deck position;
- SoundSwitch AutoLoop progress never scrubs during continuous playback.

## Physical result

The presentation-only activation repair passed: foreground switching added no
engine command and the waveform restarted from the current visual clock. The
three-packet authority rule failed the longer transport soak. With the MIDI
lane still at p95 0.1 ms and zero late dispatches/saturation, normal physical
playback accumulated multiple false discontinuities and hard Link re-anchors.
This release was not promoted; dev-46 replaces consensus-only acceptance with
pitch-correct projection and independent absolute-beat corroboration.
