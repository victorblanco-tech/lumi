# 0.5.2-dev-5 retired-path cleanup

This hardening slice removes code that could no longer be reached through the
supported product workflow.

## Product boundary

- trusted Rekordbox OneLibrary USB media remains the supported library source;
- the old XML folder discovery, mirror preview and closed-database analysis UI
  is no longer compiled into the macOS product;
- the active exactly-once AutoLoop executor is the sole runtime scheduler;
- old predictive scheduling code hidden behind `cfg(any())` has been deleted.

The session, library and SQLite fault-test modules now live in focused source
files. This reduces the production implementation files while preserving the
same private-module characterization coverage.

Architecture checks reject both retired Swift presentation types and disabled
timing implementations if they are reintroduced.

## Verification

- `swift test --package-path apps/macos/Packages/LumiLibraryWorkspace`
- `cargo check --workspace`
- `scripts/check-architecture.sh`
- full Rust and Apple verification before the development release is pushed
