# Lumi 0.5.0-dev-38

## Fixed compact navigation

The left navigation now has two user-controlled states only:

- **Visible**: the complete navigation with labels and Lumi wordmark.
- **Hidden**: a permanent 52-point icon rail whose destinations remain fully
  interactive.

Pointer hover no longer participates in navigation state. This prevents the
workspace from resizing whenever the pointer crosses the rail. The Lumi mark in
the compact rail is the deliberate show action; the sidebar button in the full
navigation is the deliberate hide action.

The existing preference storage key remains unchanged, so installations that
already had navigation hiding enabled retain the compact state after upgrading.

## Acceptance

1. Hide the full navigation with `Hide navigation`.
2. Leave the pointer over the compact rail; its width remains fixed.
3. Select Live, Library, Light Plans, Integrations and Settings from their
   compact icons; the destination changes without expanding the rail.
4. Select the Lumi mark; only this deliberate action restores the full
   navigation.
