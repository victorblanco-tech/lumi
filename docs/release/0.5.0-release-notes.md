# Lumi 0.5.0

Lumi 0.5.0 is the first complete USB-to-show production workflow. It turns a
Rekordbox-prepared USB library into editable Lumi phrases and deterministic
SoundSwitch lighting decisions, then follows real Pro DJ Link decks or Lumi's
local players during a show.

## Highlights

- **USB-first Library** — trust distinct OneLibrary USB devices, browse their
  real playlist hierarchy, preview changes and synchronize selected playlists
  without modifying the source media.
- **Track preparation** — verify the imported beatgrid, RGB waveform and Hot
  Cues; edit Lumi-owned phrases; protect finished work; and move tracks through
  configurable preparation queues.
- **Live Decks and Local Playback** — use the same Library analysis with real
  players or a dry-run local workflow, including master handoff, Hot Cue and
  Beat Jump recovery.
- **Isolated show lanes** — Pro DJ Link observation, Ableton Link BPM relay and
  SoundSwitch MIDI output run independently from UI rendering.
- **Light Plans** — combine Phrase Role, Track Color, Theme eligibility,
  variation and repeat protection into a plan compiled before playback.
- **SoundSwitch output** — map four banks with 32 AutoLoops each, learn and test
  MIDI signals through the Virtual Controller, and map Static Looks.

## Clean production installation

The production app uses bundle identifier `co.victorblan.tech.lumi` and stores
its database in `~/Library/Application Support/Lumi`. A fresh 0.5.0 production
installation starts with:

- no tracks or playlists;
- no trusted USB identities;
- no user-authored Phrase timelines;
- no personalized Bank, AutoLoop, Static Look or Light Plan configuration;
- the generic Lumi Phrase Roles and empty/configurable SoundSwitch workflow
  needed to begin setup.

Dev data under `~/Library/Application Support/Lumi Dev` is never copied into
Production automatically. This intentionally leaves an explicit, auditable
migration path for selected MIDI/output configuration later.

## Installation

1. Download `Lumi-0.5.0-arm64.dmg` and its `.sha256` file from GitHub Releases.
2. Verify the checksum.
3. Open the DMG and drag Lumi to the included **Applications - Lumi** shortcut.
4. If macOS blocks the unsigned build, follow the `README - Install Lumi.txt`
   file included in the DMG.

## Requirements and limitations

- Apple Silicon Mac running macOS 15 or newer.
- Rekordbox OneLibrary USB media for the supported import workflow.
- SoundSwitch is required for the current lighting-output profile.
- Pro DJ Link hardware is optional when using Local Playback.
- The build is ad-hoc signed and not notarized. No paid Apple Developer account
  is required, but macOS displays an initial security warning.
- iPhone Companion and automatic color override output are not included in
  0.5.0.
