# Lumi 0.6.0-dev-4 – isolated Remote projection

This increment connects the autonomous engine to the still fail-closed Remote
Gateway without exposing a LAN listener yet.

## Included

- a second, authenticated loopback-only engine endpoint dedicated to Remote;
- an explicit path-free Live projection with full state only on real static
  changes;
- coalescible 20 Hz transport anchors for playhead, beat and effective BPM;
- bounded, revision-safe Remote command handoff into the authoritative engine
  reducer;
- independent gateway disconnect behavior: losing Remote never parks the show;
- protected service-record validation and loopback enforcement;
- end-to-end authentication, snapshot, command-result and stale-state tests;
- iPhone leader-anchor handling that keeps displayed Ableton Link tempo current.

## Performance boundary

Desktop snapshot polling no longer forces complete waveform projections. Remote
publication remains outside the SoundSwitch and Ableton Link output lanes and a
slow gateway must reconnect for a fresh snapshot rather than blocking the engine.

## Deliberately not enabled

The gateway still does not bind the LAN. Pinned TLS, persistent device trust,
Mac approval/revocation UI and physical-iPhone acceptance are the next gates.
