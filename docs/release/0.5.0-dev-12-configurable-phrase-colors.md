# Lumi 0.5.0-dev-12 — Configurable Phrase Colors

## Outcome

Every Lumi Phrase Role now has one user-configurable color. Change it under
`Settings > Phrase Model`; the authoritative color is then used consistently in
the Track Editor, Live Decks, Light Plans and SoundSwitch MIDI mapping views.

## Safety

- the color is presentation-only and cannot influence plan compilation or
  realtime output timing;
- existing Phrase Role IDs, names, ordering, phrases, AutoLoops and Static Looks
  are preserved by the schema-v15 migration;
- updates use the existing optimistic catalog revision and survive restart and
  database backup/restore;
- legacy snapshots and custom roles retain a visible safe default.

## Verification

- domain, mutation, persistence and migration tests cover defaults, invalid
  values, revision conflicts and restart;
- Swift package tests cover snapshot decoding and the shared palette;
- the full Apple build and a headed desktop test verify one changed role color
  across Settings, Library, Live and Integrations.
