# Lumi 0.5.0-dev-13 — Editor Phrase Color Fidelity

## Outcome

Phrase colors in the Track Editor now match the full 24-bit sRGB value chosen
under `Settings > Phrase Model`. The detailed phrase lane and compact overview
no longer darken the configured color through opacity blending.

## Editing clarity

The selected beat range remains visible through its accent outline and handles.
Lumi no longer draws a translucent accent fill over the phrase, so selection
does not alter the perceived phrase color.

## Safety

This is a presentation-only change. Phrase data, Light Plans, MIDI mappings and
the realtime lighting-output paths are unchanged.

## Verification

- Lumi Library Workspace tests
- macOS Apple verification gate
- headed Track Editor comparison against the Settings color swatch
