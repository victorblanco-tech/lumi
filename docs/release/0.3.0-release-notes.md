# Lumi 0.3.0

Status: **Stable owner release**
Date: **2026-08-09**

Lumi 0.3.0 is the first installable end-to-end SoundSwitch Live MVP for Apple
Silicon. The exact `0.3.0-rc.1` product behavior was accepted with a physical
Local Playback → MIDI → SoundSwitch → Control One → DMX lighting run.

## Included

- read-only Rekordbox playlist and analysis import into Lumi-owned storage;
- RGB Track Lighting Editor with the Rekordbox beatgrid and editable Lumi
  phrases;
- stable two-deck Local Playback with a rolling phrase and AutoLoop Plan;
- persistent four-bank/32-slot SoundSwitch mappings;
- automatic phrase-boundary MIDI output and Local Playback MIDI Clock;
- signed -250…+250 ms output timing compensation;
- isolated Stable, Preview and Dev identities, preferences and databases;
- local data backup and explicit non-overwriting channel clone tools.

The physical acceptance run also confirmed that Control One can operate in
parallel and that its buttons reflect Lumi's active bank and AutoLoop selection.

## Install

Download both assets:

- `Lumi-0.3.0-arm64.dmg`
- `Lumi-0.3.0-arm64.dmg.sha256`

Verify the checksum, open the DMG and drag **Lumi** to Applications. This early
release is ad-hoc signed and not Apple-notarized, so macOS may require the
documented one-time **Open Anyway** action.

## Known minor issues accepted for 0.3.0

- after pause, cue/seek and play, automatic lighting can intermittently remain
  silent until a later state change re-establishes output;
- changing the lighting timing offset while Live should apply immediately to
  subsequent transport observations, but the UI does not yet distinguish the
  locally requested value from the engine-confirmed value;
- 20 ms is small enough that visual confirmation by eye is unreliable;
- the engine is still an app-scoped helper rather than an autonomous service;
- connected decks use the Beat Link Trigger MIDI adapter; production Pro DJ
  Link hardware evidence is pending;
- no iPhone companion release yet.

The first two items are explicitly scheduled for the next development cycle and
do not require re-entering Banks, AutoLoops, phrase roles or track timelines.
