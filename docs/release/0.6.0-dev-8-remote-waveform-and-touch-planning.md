# Lumi 0.6.0-dev-8 / Remote 0.1.0-dev-6 – waveform parity and touch planning

This paired development build removes the final visual mismatch between the
Mac and iPhone waveforms and makes future Light Plan choices directly
adjustable from the Remote Live surface.

## Waveform parity

The previous bounded preview independently retained the peak of every stored
frequency channel. Neighbouring red, green and blue peaks could therefore
become one synthetic pale sample that never existed in the Rekordbox analysis.

The bounded preview now selects the loudest complete source sample in every
bucket. Peak height remains present, but its original RGB relationship is
preserved. The shared `LumiRGBWaveformSample` mapping, amplitude curve, opacity
and black background then produce the same visual language on Mac and iPhone.

This is visual-only work. It does not enter the Pro DJ Link, Ableton Link or
lighting output timing lanes.

## Touch planning

- Tap a coloured Phrase segment or its proportional Light Plan block.
- Select another Phrase from the compact sheet without closing it.
- Inspect its Theme/Bank, AutoLoop, Static Look and lock state.
- Change Theme/Bank or AutoLoop and lock or unlock the choice while the phrase
  is still upcoming.
- Running and completed phrases remain visible and inspectable, but immutable.
- Viewer devices can inspect the plan; only the current Controller can change
  it.

## Automated evidence

- bounded waveform downsampling retains a complete source hue;
- future, live and completed phrase classification has deterministic tests;
- only an upcoming phrase with Controller access becomes editable;
- existing Remote exactly-once command validation remains authoritative.

## Headed acceptance

The packaged Mac dev-8 engine and signed Remote dev-6 app were connected through
the real TLS gateway to the LAN Pro DJ Link simulator. `90s Bitch - Extended
Mix` rendered with distinct cyan, red and pink waveform regions. Two captured
states six seconds apart showed both the remaining time and the waveform
viewport following live playback.

The actual iPhone Simulator UI then opened `Adjust Light Plan` from an upcoming
Phrase. The sheet exposed Phrase, status, Theme/Bank, AutoLoop and lock controls.
Selecting the running Drop changed the status to `Live · locked` and disabled
all mutation controls, while the next Intro remained `Planned · adjustable`.
No lighting command was sent during this visual acceptance.
