# Lumi 0.6.2-dev-8 — One saved timing setting

Remote offset changes now update the same permanent setting as Mac edits.
Remote 0.1.1-dev-4 remains compatible; no new iPhone binary is required.

- Channel-local engine persistence survives restart and does not require a UI
  observer to save changes.
- File I/O is isolated on a bounded background writer. Live integration paths do
  not wait for disk writes. Failed writes are visible in Mac Live, not reported
  as SAVED.
- Mac migrates its previous preference once and mirrors saved engine values
  without resending them. SESSION is removed.
- Changes during Start/playback still activate at the next phrase, without
  restarting the active AutoLoop.
