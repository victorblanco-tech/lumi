# Lumi 0.6.0 release readiness

## Release identity

- Lumi version: `0.6.0`
- Lumi Remote version: `0.1.0`
- status: Public Beta
- macOS channel: Production
- macOS bundle identifier: `co.victorblan.tech.lumi`
- macOS data: `~/Library/Application Support/Lumi`
- platforms: Apple Silicon macOS 15+ and iPhone iOS 18+

## Scope and data safety

0.6.0 adds the independently supervised Remote Gateway and native iPhone
companion without placing either in a show-critical integration lane. It does
not require a product-schema reset. A Production upgrade preserves the existing
library and configuration; a clean install remains empty.

The DMG and iOS source contain no tracks, trusted USB identities, authored
phrases, SoundSwitch mappings, pairing credentials or other personal data.

## Acceptance evidence

- Physical iPhone testing proved saved pairing, live RGB waveform motion,
  realtime BPM changes, Hot Cue changes and Master handoff against real Players.
- Portrait presents the Master first and its prepared next Player below it;
  landscape presents both Players side by side without removing their phrase
  or Light Plan context.
- Pro DJ Link, Light Output and Ableton Link status remain visible during
  discovery, reconnect and normal operation.
- Remote transport anchors are translated into the iPhone clock domain and the
  native renderer remains bounded independently from Mac UI rendering.
- The Remote Gateway has a separate lifecycle, bounded queues and pinned-TLS
  trust. Disconnecting the Remote cannot stop or steer an already running show.
- The production icon, privacy documentation, Xcode installation path and
  independent product-tag checks are included.

## Publication contract

The exact release commit receives both `v0.6.0` and
`lumi-remote-v0.1.0`. The first tag creates the controlled macOS draft with DMG,
SHA-256 checksum and SPDX SBOM. The second creates a separate Lumi Remote draft
with its iOS Simulator validation artifact and checksum.

Both drafts are reviewed before publication. The Remote asset is not an IPA and
cannot be installed on a physical iPhone; physical installation remains the
documented Xcode source route until TestFlight distribution is enabled.

The macOS app remains ad-hoc signed and intentionally not notarized.
