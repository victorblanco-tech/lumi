# `0.4.0-dev-41` monotonic Ableton Link timeline

## Physical finding

AutoLoop selection arrived on the intended phrase boundary, but SoundSwitch's
active AutoLoop progress sometimes moved several beats backwards and forwards
while the CDJ played normally. Diagnostics from the affected session showed:

- 843 applied Pro DJ Link timing anchors;
- 575 hard Link re-anchors;
- 238 soft Link corrections;
- 768,425 microseconds maximum absolute phase error.

The implementation was treating every UDP receive timestamp as a clock phase
measurement. Arrival jitter therefore became a musical timeline correction.

## Correction

- Exact Pro DJ Link beats continue to schedule phrase-boundary AutoLoop MIDI.
- A running Link timeline is monotonic within one timing generation.
- Continuous anchors can change BPM without changing phase.
- Initial start/resume, Hot Cue or seek, track load and Master handoff create a
  new authoritative phase anchor.
- Continuous phase error remains visible as diagnostics and never becomes a
  backward/forward correction command.
- Every app-owned engine uses an isolated free local Carabiner control port in
  the helper's accepted `20000...32767` range, so it
  cannot inherit an orphan from another Dev/RC/Prod process and always owns the
  helper it must terminate.

## Required acceptance

- Run a physical or network-simulated master track through several phrase and
  loop boundaries with SoundSwitch connected.
- Confirm AutoLoop progress never scrubs backwards during continuous play.
- Confirm a start/resume and a real seek each re-anchor once.
- Confirm phrase switches still dispatch inside the existing realtime budget.
- Confirm normal Quit leaves no Lumi-owned Link helper or peer behind.
