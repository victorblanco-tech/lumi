# Lumi 0.1.0 demo and known limitations

This guide covers the unsigned `0.1.0-dev` Epic 1 milestone. A tester can run
the complete demo in the macOS app without Terminal, internet, DJ hardware,
Rekordbox, SoundSwitch, or licensed music.

## Demo in the app

1. Open `Lumi.app` in Finder. For the unsigned development build, use
   **Control-click → Open** if macOS asks for confirmation.
2. Wait until Local Lumi Engine, Runtime, Deck Source, Planner, and Lighting
   Output Provider all show **READY**.
3. Click **Load Demo**, then **Pause Demo** to freeze the simulated decks while
   reviewing the prepared Next-track plan.
4. Select the Breakdown phrase for **Neon Horizon**, choose **Deep Space**, and
   click **Lock cue**. The plan revision must increase after each accepted edit.
5. Select **64×**, then click **Arm** and **Start**. Arm reads and plans; Start
   opens the engine's dry-run output gate.
6. Click **Next Track**. Neon Horizon becomes Live and its exact prepared plan
   becomes active. Click **Resume Demo** to run the track.
7. Inspect **Engine Event Timeline**. Phrase changes appear in monotonic order
   and dry-run records show `SIMULATED` with their reducer reason.
8. Use the top **Pause** button to close output while preserving state. **Start**
   resumes at the next phrase boundary; **Off** clears the active output plan.
9. Click **Reset** to restore the canonical two-deck session without restarting
   the app.

The same automated scenario runs at every release gate and is reviewed in
[`fixtures/demo-session-v1/canonical-e2e.json`](../../fixtures/demo-session-v1/canonical-e2e.json).

## Known limitations

- Output is dry-run evidence only. Epic 1 sends no live MIDI, SoundSwitch, or
  DMX commands.
- The deck source is the bundled deterministic simulator. Beat Link,
  Rekordbox, and direct Pro DJ Link adapters are not included.
- Music-library import and audio/phrase analysis are represented by
  license-safe fixture metadata; no user library is imported yet.
- The Rust engine is an app-scoped child process. LaunchAgent installation and
  background operation after the macOS UI exits are later scope.
- This milestone targets Apple Silicon macOS only. Windows and the native
  iPhone companion are later scope.
- The development app is unsigned and not notarized. DMG packaging, signing,
  notarization, auto-update, TestFlight, and App Store delivery are excluded.
- The demo timeline retains the latest 256 entries and dry-run output retains
  the latest 256 records by design.
- The app and engine require no runtime internet access; GitHub is used only
  for development and release evidence.
